Troubleshooting

Common snags during setup and everyday chatting, matched by symptom so you can resolve them quickly.

Windows SmartScreen Prompt During Install

Because this independent open-source build does not yet carry a commercial EV code-signing certificate, Windows SmartScreen displays a standard unsigned-publisher warning the first time you run nyairo-0.7.0-setup.exe. Click More info in the dialog, verify that the application name matches the official SHA256 fingerprint published on the site, and then click Run anyway in the bottom-right corner to proceed (see the dual-panel diagram at Installing on Windows · 2-Step SmartScreen Walkthrough).

nyairo Command Not Found / WSL Won't Open

  • nyairo returns command not found right after install: The current terminal session has not reloaded the newly updated PATH. Close and reopen the terminal window, or run export PATH="$HOME/.local/bin:$PATH".
  • Windows Desktop reports WSL 2 is not detected: Open PowerShell as Administrator, run wsl --install -d Ubuntu, reboot your PC, launch Ubuntu once from the Start menu to set up a Linux username and password, and then reopen the nyairo desktop client.

401 Errors or Connection Timeouts When Chatting

  • 401 Unauthorized: Your API key is missing, incorrect, or expired. Check for stray leading/trailing spaces from copy-pasting, confirm you selected the right provider endpoint (for example, entering a DeepSeek key against the official OpenAI URL), and verify your account has remaining credit. Re-enter it in the desktop "Settings" tab or run nyairo setup model in the terminal.
  • Continuous spinner / timeout: If you are using a remote model API (such as OpenAI or Claude), confirm that your network environment—including inside WSL—can reach that endpoint reliably.

Companion Doesn't Seem to Remember Past Chats

  1. Send /chiyo_status in chat and check whether Memory shows READY;
  2. Send /chiyo_memory list to verify whether the facts from your conversation were recorded (casual small talk is not stored line by line; explicit personal preferences, experiences, and commitments are saved);
  3. If you are using the desktop app and just clicked "New Chat": note that if more than 15 minutes have passed since your previous message, unsealed earlier episodes are not automatically injected into a brand-new session by default (see Desktop Memory Recall Window). For everyday continuity, continue within the same conversation thread.

Telegram 409 / Silent QQ Bot / Running in Background

  • Telegram reports 409 Conflict: terminated by other getUpdates request: Two gateway processes are polling the same bot token at the same time (for instance, the desktop app's background gateway is running while you also executed nyairo gateway run in a terminal). Stop the duplicate process to resolve the conflict immediately.
  • QQ bot shows connected, but ignores private messages: Check two things—first, the config key name must be qqbot (writing qq is ignored); second, you must allowlist your private chat session under "Who can talk to them" in the desktop app or inside gateway_bindings.qqbot in chiyo/config.json (see QQ Bot Setup & Pitfalls). If it still fails, export a redacted diagnostic bundle in one click from desktop "Settings → Environment & Diagnostics".
  • Running continuously at boot on a Linux server: If you host nyairo on an always-on Linux machine, create a systemd unit file at /etc/systemd/system/nyairo-gateway.service (replace your-username with your actual Linux username):
ini
[Unit]
Description=nyairo messaging gateway
After=network-online.target

[Service]
Type=simple
User=your-username
WorkingDirectory=/home/your-username
Environment=HERMES_HOME=/home/your-username/.nyairo
ExecStart=/home/your-username/.local/bin/nyairo gateway run
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target

After saving, run sudo systemctl daemon-reload && sudo systemctl enable --now nyairo-gateway.service to keep the gateway running in the background.
