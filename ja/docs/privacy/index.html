プライバシーとデータの境界線

どのデータがあなたの PC 内に留まり、どの内容が対話時にモデル API へ送信されるのか、そして「記憶の削除」が実際に何を行っているのかを正直に説明します。

あなた自身の PC に留まるデータ

モデルの API キー、WeChat / Telegram の連携認証情報、完全なチャット履歴、SQLite 長期記憶データベース、生活状態帳簿、およびアルバム・原稿は、すべてあなたのローカル PC 内の個人ディレクトリ（初期設定は ~/.nyairo）に書き込まれます。nyairo のいかなるサーバーも経由しません。nyairo 公式に中央集権型のクラウドバックエンドは存在せず、あなたのプライベートな会話データベースを収集することは一切なく、仕組み上収集もできません。

ローカル権限に関するご注意：現在のバージョンではローカルデータベースに対する透過的ディスク暗号化を行っていないため、データの安全性はお使いの PC の OS アカウント権限に依存します。同じ PC の管理者（root）権限を持つ人や、ユーザーディレクトリを読み取れるローカルソフトウェアは理論上これらのファイルを参照できるため、端末とバックアップアーカイブはご自身で大切に管理してください。

ネットワーク経由で外部へ送信される内容

「ローカルデプロイ」は「完全にネットワーク遮断」と同義ではありません。普段の利用でネットワーク通信が発生するのは、あなたがご自身で設定した次の箇所に限られます：

  • あなたが選んだ LLM プロバイダー：対話のたび（またはバックグラウンド活動や /chiyo_consider 分析の実行時）に、現在の入力・直近の会話コンテキスト・検索された関連記憶の断片が、返信生成のためあなたが入力したモデル API アドレスへ直接送信されます。nyairo のいかなるサーバーも経由しません。Ollama などのローカルモデルを使えば、データを一切 PC の外へ出さずに完結させることも可能です。
  • メッセージングプラットフォーム（任意）：WeChat や Telegram を連携している場合、やり取りされるメッセージは当然ながら各プラットフォームの通信経路を通過します。
  • 本ガイドサイト（nyairo.com）：純粋な静的 Web サイトであり、検索処理もブラウザ内のローカルで動作します。ライト／ダークテーマの設定もブラウザの localStorage にのみ保存され、あなたのローカルインスタンスへ接続することはありません。

「呼び出し停止」と完全消去の違い

  • /chiyo_memory delete が行うこと：指定した記憶を無効化マークし、以降の対話コンテキストを組み立てる際に関連する古い断片を除外して、モデルが今後その話題に触れないようにします。あわせて、モデルがコマンドラインを呼び出して過去のログファイルを直接読み返す権限も既定で制限しています。
  • 行わないこと：これはディスクの完全消去ツール（シュレッダー）ではありません。障害切り分けや遡及確認のため、元のセッション記録・監査ログ・過去に手動で作成したバックアップアーカイブには当時の文章がそのまま残ります。また、モデルプロバイダー側や WeChat / Telegram 側の履歴メッセージがこのコマンドで遠隔取り消しされるわけでもありません。
  • ローカルデータ一式を完全に消去する方法：実行中のすべての nyairo およびゲートウェイプロセスを停止し、記憶を一切残さなくてよいことを確認したうえで、~/.nyairo ディレクトリおよびご自身で保存していたバックアップアーカイブを手動で削除してください。

不具合報告時に個人プライバシーを守る方法

GitHub に Issue を投稿したりコミュニティグループへエラー画面を貼ったりする前に、機微情報が含まれていないか一度ご確認ください：

  • .env、config.yaml、または ~/.nyairo フォルダ丸ごとをそのまま貼り付けないでください。
  • API キー、Telegram Bot Token、個人の数値 Chat ID、WeChat 連携用 QR コード、実際のシステムユーザー名は切り抜くかマスクしてください。万一公開ページにキーを貼ってしまった場合は、投稿を削除するだけでは不十分ですので、ただちに該当サービスの管理画面からキーを失効させて再発行してください。
