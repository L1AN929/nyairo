Linux 環境および手動インストール

各ステップのスクリプトを自分で確認したい方や、リリースアーカイブを手元に保存したい方、サーバーへ手動デプロイしたい方向けの手順です。

はじめにお読みください

すでに curl -fsSL https://nyairo.com/install.sh | bash の 1 行コマンドでインストール済みの場合、本章の手順は一切不要です。そのまま 普段の起動・人物設定・モデル設定 へお進みください。本章は、各工程を手動で確認しながら導入したい方向けの解説です。

ステップ 1：基本システムツールの準備

Linux ターミナル（または Windows の Ubuntu ターミナル）で必要な基本ツールを揃えます（Ubuntu / Debian の例）：

bash
sudo apt update
sudo apt install -y git curl unzip ripgrep less nano python3

現在の Linux アカウントのパスワードを入力して Enter を押し、エラーが出ていないことを確認してから次へ進んでください。

ステップ 2：uv と Python 3.13 の準備

本プロジェクトは独立した Python 環境と依存パッケージを管理するために uv を使用しており、システム標準の Python 環境を汚すことはありません。実行前にスクリプトをダウンロードして中身を確認してから進めることもできます。

bash
curl -LsSf https://astral.sh/uv/install.sh -o /tmp/uv-install.sh
less /tmp/uv-install.sh
sh /tmp/uv-install.sh

内容確認を終えたら q キーで less を閉じます。インストール後、新しいターミナルウィンドウを開き直して Python 3.13 を取得してください。

bash
uv --version
uv python install 3.13

ルート A：Git タグを指定してクローン・導入する

ルート A とルート B はどちらか一方を選べば十分です。Git を使う場合は、リリース済みの固定タグ v0.7.0 をチェックアウトしてください（変更が続く開発ブランチをそのまま導入しないようご注意ください）。

bash
mkdir -p "$HOME/apps"
git clone --branch v0.7.0 --depth 1 \
  https://github.com/L1AN929/nyairo.git "$HOME/apps/nyairo-v0.7.0"
cd "$HOME/apps/nyairo-v0.7.0"
bash scripts/bootstrap.sh

固定タグをチェックアウトすると Git が detached HEAD と表示しますが、これは正常な状態です。インストール完了後、以下のマニフェスト自己チェックを実行してすべてのファイルが欠損なく揃っていることを確認できます。

bash
~/.local/share/nyairo/releases/v0.7.0/vendor/hermes/.venv/bin/python -B \
  ~/.local/share/nyairo/releases/v0.7.0/scripts/verify_manifest.py

出力に "valid": true が含まれていれば、ファイル構成の検証が完全に一致したことを示します。

ルート B：公式 ZIP をダウンロード・検証して導入する

先にリリースアーカイブを手元に保存し、ハッシュを照合してから展開・導入したい場合は次の手順で行います。

bash
mkdir -p "$HOME/apps" && cd "$HOME/apps"
curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.7.0/nyairo-v0.7.0.zip
curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.7.0/nyairo-v0.7.0.zip.sha256
sha256sum -c nyairo-v0.7.0.zip.sha256

画面に nyairo-v0.7.0.zip: OK と出力されたことを確認したら、アーカイブを展開して同梱のインストーラーを実行します。

bash
python3 -m zipfile -e nyairo-v0.7.0.zip "$HOME/apps/nyairo-v0.7.0"
cd "$HOME/apps/nyairo-v0.7.0"
bash scripts/bootstrap.sh

Windows 側のブラウザで事前に ZIP をダウンロードしてある場合は、WSL 内から /mnt/c/Users/あなたのWindowsユーザー名/Downloads/nyairo-v0.7.0.zip のように参照できます。

すでに Hermes を導入済みの環境について

既存の Hermes を削除する必要はありません。nyairo はバージョン整合性を検証済みの専用 Hermes 環境を内部に備えており、データも ~/.nyairo 配下に独立して管理されるため、既存の環境と干渉することはありません。ただし、nyairo のプラグインディレクトリを別バージョンの Hermes へ手動でコピーして混在させると、インターフェースの違いによりエラーの原因となりますのでお控えください。
