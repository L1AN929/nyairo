データディレクトリ、バックアップとアンインストール

各フォルダに何が保存されているか、サービスを停止して完全なバックアップを取る手順、PC 買い替え時のデータ移行方法、そして目的に応じたクリーンなアンインストール手順を解説します。

各フォルダに保存される内容

パス保存されている内容バックアップの推奨度
~/.nyairoキャラクター設定 SOUL.md、モデルおよびプラットフォーム設定、チャットセッション、長期記憶 SQLite データベース、生活状態およびレシートログ中核となる個人データのため、ディレクトリごと必ずバックアップしてください
~/.local/share/nyairo各バージョンの読み取り専用プログラムソースコード、同梱の Hermes および Python 仮想環境バックアップ不要（再インストールやアップデートでいつでも再構築可能です）
~/.local/state/nyairo現在有効なバージョン番号とインストール状態の記録（install.json）再インストール時に自動生成されるため、バックアップは任意です
%LOCALAPPDATA%\Programs\nyairoWindows ネイティブデスクトップクライアントの UI プログラム（Windows のみ）バックアップ不要（インストーラーから再インストールできます）
%LOCALAPPDATA%\nyairoWindows デスクトップ版のローカル接続先設定（config.json）および UI 実行ログ（desktop.log）再インストール時に残しておくと、元のインスタンスを自動で再認識できます

ご注意：~/.nyairo には API キー、プラットフォーム連携用の認証情報、すべてのプライベートな会話が含まれています。作成したバックアップアーカイブはご自身のプライベートなストレージに厳重に保管し、公開オンラインストレージやコードリポジトリにはアップロードしないでください。

サービスを停止した正しいバックアップ手順

内部で SQLite データベースを使用しているため、バックアップを取る前に必ず実行中のチャット画面、デスクトップ版のバックグラウンドゲートウェイ、または systemd サービスをすべて停止してください。プログラムがデータベースへ書き込みを続けている最中に .db ファイルだけを直接コピーすると、メイン DB にまだ統合されていない一時ログ（WAL）を取りこぼし、復元時にデータが欠損したり破損したりする恐れがあります。

バックグラウンドプロセスが動いていないことを確認したうえで、ディレクトリ全体をアーカイブし、ファイル権限を厳しく制限してください：

bash
mkdir -p "$HOME/nyairo-backups"
chmod 700 "$HOME/nyairo-backups"
bkp="$HOME/nyairo-backups/nyairo-data-$(date +%Y%m%d-%H%M%S).tar.gz"
tar -czf "$bkp" -C "$HOME" .nyairo
chmod 600 "$bkp"
tar -tzf "$bkp" >/dev/null && echo "バックアップの整合性チェックに成功しました：$bkp"

現在 PC を買い替える際のデータ移行方法

現在の v0.8.0 では、API キーとローカルパスを自動除外するロスレス引越しスーツケース（.nyairo-suitcase.zip）のエクスポートに対応しています。デスクトップ版で「設定 → 環境と診断」（または概要ページの「引越しスーツケース」カード）を開き、「ポータブルスーツケースを書き出す (.nyairo-suitcase.zip)」をクリックすると、二層メモリーランタン帳簿、エッセイや作品、生活の進行状態に加えて現在のカスタム／ランダムワールドのスライスと透明性の高い「移行ロス一覧」一式をまとめてパッケージ化できます。新しい PC にインストールした後、同じ画面から「スーツケースファイルを選択してインポート復元」をクリックし（2段階の安全事前チェックが自動実行されます）、モデルキーを再入力すれば完了です。

ローカルのキーファイルやゲートウェイのホワイトリストも含めて低レイヤーでディレクトリごとコピー移行したい場合は、次の4ステップで手動移行することもできます：

  1. 旧 PC で nyairo とゲートウェイプロセスを完全に終了し、上記のコマンドで ~/.nyairo を .tar.gz にまとめます。
  2. 新 PC に同じバージョン（v0.8.0）の nyairo をあらかじめインストールしておき、まだゲートウェイは起動しないでください。
  3. USB メモリまたはローカルネットワーク経由でバックアップアーカイブを新 PC（WSL 環境）へ転送し、新 PC の ~/.nyairo に上書き展開します。
  4. パスの違いを確認：旧 PC と新 PC で Linux ユーザー名が異なる場合（例：旧 PC が alice、新 PC が bob）、~/.nyairo/chiyo/config.json と ~/.nyairo/config.yaml を開き、旧ユーザー名の絶対パス（/home/alice/... など）が固定記載されている箇所を新しいユーザー名のパスへ書き換えてからプログラムを起動してください（同じ Telegram Token を使って2台の PC を同時にオンラインにすることは絶対に避けてください）。

クリーンにアンインストールする方法（記憶を残す vs 完全に消去する）

利用を終える場合やトラブルシュートのため再インストールしたい場合は、「記憶を残すかどうか」に応じて次の2通りの方法で対処できます：

  • ケース 1：クライアントプログラムのみを削除し、すべての記憶とキャラクター設定を残す（再インストール時に推奨）
    • Windows デスクトップ版：Windows の「設定 → アプリ → インストールされているアプリ」から nyairo をそのままアンインストールします（または %LOCALAPPDATA%\Programs\nyairo\unins000.exe を実行します）。アンインストーラーは自動起動用のレジストリ項目をクリーンアップし（起動時エラーを防止）、WSL 内のゲートウェイを停止してウィンドウキャッシュを削除しますが、WSL 内の個人データディレクトリには一切触れません。後から再インストールすればシームレスに引き継げます。
    • Linux / WSL コマンドライン：ゲートウェイを停止した後、プログラム本体とコマンドの入り口だけを削除します：rm -rf ~/.local/share/nyairo ~/.local/state/nyairo ~/.local/bin/nyairo。
  • ケース 2：プログラム本体とすべてのチャット記憶・設定を完全に削除する（復元不可のため、バックアップ不要であることを事前にご確認ください）
    1. Windows デスクトップ版を導入している場合は、まず上記の手順でシステムのアプリ一覧からデスクトップクライアントをアンインストールし、続けてローカル設定ディレクトリを削除します（PowerShell で Remove-Item -Recurse -Force "$env:LOCALAPPDATA\nyairo" を実行）。
    2. Linux の systemd 常駐サービスを設定していた場合は、先に sudo systemctl disable --now nyairo-gateway.service を実行し、対応する unit ファイルを削除します。
    3. Linux / WSL ターミナル上でプログラム本体と個人データディレクトリを削除します：
bash
rm -rf "$HOME/.nyairo" "$HOME/.local/share/nyairo" "$HOME/.local/state/nyairo" "$HOME/.local/bin/nyairo"
