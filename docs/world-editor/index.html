地图编辑器与世界包

怎么一键生成免选风貌的全随机专属世界、切换 7 套内置世界与 4 种主题风格、使用深浅双色离线地图编辑器改建店铺与房间，以及当前的真实工程边界。

随包附带的 7 套世界与 12 类街区店铺

首次安装默认进入临海小镇「凪浦」（凪读作「止」zhǐ），在发行包的 examples/worlds/ 目录下随附了 7 套不同地貌的完整世界包（外加 1 份经编辑器改建的演示包 nagiura-edited），涵盖 12 类街区商业与公共店铺及开放柜台自由点单（例如去便利店买一份热关东煮，而旧书店与咖啡屋店主各自拥有独立错峰作息，并支持在吧台留下杯垫留言）：

  • 临海小镇 · 凪浦（nagiura，凪读作「止」zhǐ）：默认示例世界，包含住居、书店、海鸥咖啡、公园、海滩等 17 处地点与 18 条道路（另有改建演示 nagiura-edited，18 处地点、19 条道路）；
  • 山间温泉镇 · 汤川（onsawa）与岭谷（mountain_town-demo）：包含翠泽汤屋（hot_spring）、山间石阶与溪谷景致，各 15 处地点；
  • 田园乡野 · 穗村（inobe）与泽乡（rural_farming-demo）：包含水车公园、田埂小路与村落工坊，各 14–15 处地点；
  • 日常街区 · 栞泽（wakaba，栞读作「刊」kān）与日常街区·一（daily_neighborhood_v1）：前者包含栞泽书店与 16 处生活街区，后者提供带营业时间与阅读角的轻量 7 地点生活圈。每个世界目录下均附 preview.html，双击即可在浏览器查看路网拓扑图。

深浅双色离线地图编辑器：画房间与设店铺

仓库 components/world-editor/ 内置了一套焕新升级、支持深色与浅色双主题切换的纯本地可视化空间编辑器（只监听本机 127.0.0.1，无需联网、不耗模型额度）。你可以直接从桌面端「街区 → 编辑器」标签展开使用，也可以在终端手动启动它：

bash
cd ~/.local/share/nyairo/releases/v0.7.0/components/world-editor
python3 server.py --port 8766

随后在浏览器打开 http://127.0.0.1:8766，就可以动手改造世界了：

  1. 把现有世界包转成编辑器格式：运行 python3 -m components.worldgen editor-export examples/worlds/nagiura，会在包内生成 editor-world.json；
  2. 可视化改造与店铺点单配置：在浏览器里导入这份文件，随时切换深浅外观主题，自由修改书店名字和营业时间、增删街道连线、配置自定义店铺的开放柜台菜单（sale_spec），或者切进室内视图画墙、开门窗、摆放带收纳或物态特征的书桌、水壶与台灯，还能点「AI 视角预览」看看 TA 在房间里能观察到哪些家具；
  3. 一键回写并校验：点界面上的「导出 nyairo 世界包」（或用命令行 editor-import），系统只会差量更新你改过的字段，保留原有的 NPC 与环境事件，并自动做连通性检查（如果不小心把唯一出路删断了，或者删掉了还有 NPC 上班的店铺，会直接用中文指出具体冲突，防止导出坏档）。

免选风貌全随机专属世界与种子生成

在 v0.7.0 中，除了按「临海坡道小镇（coastal_town）」「山间温泉町（mountain_town）」「近郊住宅街（residential_town）」「田园农庄（rural_farming）」四种主题生成外，打开桌面端「街区 → 生成新小镇」已支持免选风貌的全随机专属世界一键生成（procedural 模式）：无需挑选预设风格，生成器会按随机种子从 6 种地貌（海岬坡道、运河水巷、山麓溪谷、铁道驿町、果园台地、林间湖畔）中混搭互补风貌，组合 4 种异构连通道路网（星型枢纽、环街回路、长街步道、分岔大道）、8 类商业店铺与多房间住宅（在卧室之外自动搭配客厅、檐廊、小厨房或书斋角及冷热干湿物态家具），并支持「生成后立即热切换生效」。

如果你在 Linux / WSL 终端使用，也可以直接调用 components.worldgen 指定 --theme procedural（或任一主题）与数字种子一键生成确定性专属世界：

bash
REL="$HOME/.local/share/nyairo/releases/v0.7.0"
cd "$REL"
# 免选预设风貌，凭种子一键生成全随机专属世界并校验、输出预览地图
"$REL/vendor/hermes/.venv/bin/python" -m components.worldgen generate \
  --theme procedural --seed 20261118 --out "$HOME/my-world"
"$REL/vendor/hermes/.venv/bin/python" -m components.worldgen validate "$HOME/my-world"
"$REL/vendor/hermes/.venv/bin/python" -m components.worldgen preview "$HOME/my-world" --out "$HOME/my-world/preview.html"

同一个模式加同一个种子，生成的道路耗时、店铺菜单与住宅房间结构逐字节可复现（全程零大模型调用）；启动世界服务时通过环境变量 CHIYO_WORLD_PACKAGE="$HOME/my-world" 即可挂载该世界包。

当前真实限制（哪些还没打通）

为了避免大家对编辑器和生成器产生误判，下面这几条尚未打通的工程边界请提前知悉：

  • 首次启动免点选的零配置初遇创世仍在打磨：桌面端「生成新小镇」与命令行 --theme procedural 已实现免选风貌的全随机专属世界，但首次安装刚打开客户端时的零提问自动创世引导与社区世界包工坊仍在 未来规划 中。
  • 墙体与地板暂不阻挡移动：编辑器里画的墙面和地面材质保存在 scene.json 中供可视化展示与后续编辑恢复；底层运行时目前按「建筑入口 ↔ 室内功能区（如卧室、客厅，切换耗时 30 秒）」的节点图寻路，还没有像素级的绕墙碰撞计算。
  • 店铺营业时段暂不支持跨午夜写法：生成世界与编辑器自定义店铺均已接通开放柜台点单（sale_spec），但店铺营业时间暂不支持跨午夜区间写法（如 22:00–06:00 回写时会明确提示不支持）。
