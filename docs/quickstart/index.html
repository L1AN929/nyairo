第一次使用，从这里开始

根据你手头的电脑选择最顺手的装法：Windows 用户直接装桌面端，新手花 5 元配好 DeepSeek 密钥或免费连本地 Ollama 就能开聊。

先选适合你的安装方式

开始前只需要准备好一台能上网的电脑，以及一个大模型接口（花 5 元配好 DeepSeek API Key，或者免费连本机 Ollama 均可）。按你的系统二选一：

  • 如果你用 Windows 10 / 11（推荐）：直接下载约 5.8 MB 的 Windows 桌面端安装包，双击安装后会自动检测 WSL 2 并引导配好后台环境，不需要自己记终端命令。完整步骤见 在 Windows 上安装，界面用法见 桌面客户端使用指南。
  • 如果你用 Linux，或习惯纯终端操作：继续看下面的一行命令安装步骤即可。
  • 如果你平时用 Claude Code / Codex 等编程助手：也可以直接把 交给 AI 助手自动安装 里的标准指令复制给它代装。

Windows 首次运行提示「已保护你的电脑」两步图解

独立开源项目暂未购买每年数千元的商业 EV 代码签名证书，首次双击 nyairo-0.7.0-setup.exe 时 Windows SmartScreen 可能会弹出常规拦截提示。按下面两步点开即可（全程无需管理员权限）：

  1. 先点弹窗文字下方的「更多信息」展开安装包详情；
  2. 可顺手核对安装包 SHA256 与官网公布的 174e459727af67c5d97204abd69dd7ce0741ed056a084fc64ba78a187bc14dd8 一致，再点右下角出现的「仍要运行」即可进入安装向导。

Linux / WSL 一行命令安装

打开你的 Linux 终端（Windows 纯终端用户请先打开 Ubuntu 窗口），复制下面这行命令并回车：

bash
curl -fsSL https://nyairo.com/install.sh | bash

想先校验再运行，可分步下载官方压缩包与校验文件：

bash
curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.7.0/nyairo-v0.7.0.zip
curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.7.0/nyairo-v0.7.0.zip.sha256
sha256sum -c nyairo-v0.7.0.zip.sha256
python3 -m zipfile -e nyairo-v0.7.0.zip "$HOME/apps/nyairo-v0.7.0"
cd "$HOME/apps/nyairo-v0.7.0" && bash scripts/bootstrap.sh

不用提前装 Python 或 Git。脚本会自动下载并校验官方 v0.7.0 发行包，配好 Python 3.13 运行环境，并在 ~/.nyairo 下建好你的个人数据目录。

看到终端提示 [5/5] 程序安装完成 后，会自动进入模型配置向导：

  1. 用上下方向键选择你的模型服务商；
  2. 粘贴你的 API Key（如果用的是第三方兼容接口，顺手填一下 Base URL）；
  3. 回车保存后就会直接进入对话界面，发一句「你好」，能收到回复就说明跑通了。
提示找不到 curl？

极少数刚装好的 Ubuntu 镜像还没带 curl，先跑一句 sudo apt update && sudo apt install -y curl 再执行上面的安装命令即可。

零基础配模型：5 元 DeepSeek 密钥或免费 Ollama

从来没申请过 API Key 也不用担心，nyairo 的确定性底座不挑昂贵模型，下面两种零门槛方式任选一种就能跑通：

  • 方式 A（省心推荐 · 无需显卡）：花 5–10 元申请 DeepSeek 密钥：浏览器打开 platform.deepseek.com 注册登录，在「充值」页充入 5–10 元（日常对话单次仅几厘钱，足够用很久），点左侧「API keys → 创建 API key」，复制生成的 sk-... 密钥，粘贴进桌面客户端「设置 → 模型」（模型选 deepseek-chat），点「保存」并「测试连通」即可。
  • 方式 B（完全免费 · 零云端流量）：直连本机 Ollama：前往 ollama.com 安装 Ollama 并拉取轻量模型（如运行 ollama pull qwen2.5:7b），保持后台监听 http://127.0.0.1:11434；在桌面端「设置 → 模型」选择本地 Ollama / OpenAI 兼容接口（地址填 http://127.0.0.1:11434/v1，密钥填 ollama），所有对话数据完全不出本机（分步细则见 日常启动、人设与模型）。

装好之后怎么聊天

  • 桌面端用户：点击桌面或右下角托盘里的 nyairo 图标就能打开窗口，在侧边栏切换「总览」「对话」「街区」「记忆」或「设置」。
  • 终端用户：平时打开终端输入 nyairo 回车就能接着聊；输入 /chiyo_status 可以看记忆（READY）与生活状态（IDLE）是否在线；想换模型随时运行 nyairo setup model。
  • 连到手机微信：希望出门在外也能用手机跟 TA 聊，按 接入微信 扫个码就能绑好。

给 TA 起名字、改性格

默认人设是一张干净的白纸。想给 TA 起个名字、定下说话语气和你们之间的称呼，用编辑器打开个人目录下的 SOUL.md 即可：

bash
nano "$HOME/.nyairo/SOUL.md"

直接用日常中文写清楚 TA 叫什么、性格偏安静还是活泼、平时怎么称呼你。改完按 Ctrl + O 回车保存，再按 Ctrl + X 退出，下次对话就会按新设定生效。
