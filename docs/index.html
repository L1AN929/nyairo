起步与安装

项目介绍与核心能力

认识 nyairo：给数字个体一方住得下来的空间、存在本机的长期记忆，以及按真实时间流动的日常。
版本动态与更新说明 NEW

如实记录每一版的改动、修补与当前还没做完的边界。当前最新公开测试版为 v0.8.0，旧版标签与安装包均保留在 GitHub Releases。
第一次使用，从这里开始

根据你手头的电脑选择最顺手的装法：Windows 用户直接装桌面端，新手花 5 元配好 DeepSeek 密钥或免费连本地 Ollama 就能开聊。
安装前准备与系统要求

装之前花一分钟确认系统环境、磁盘空间与目录结构，省去后面来回折腾。
在 Windows 上安装 桌面端

推荐使用免管理员权限的原生 Windows 桌面端（附 SmartScreen 两步矢量图解与自动环境引导），也支持纯 WSL 2 终端命令行安装。
Linux 与手动安装

适合想自己查看每一步脚本、离线保存发行包，或在服务器上手动部署的用户。
交给 AI 助手自动安装

如果你平时在用 Claude Code、Codex 或其他带终端权限的 AI 编程工具，可以把这段标准说明直接复制给它，让它先检查环境再安全安装。
日常启动、人设与模型

平时怎么唤醒 TA 聊天、怎么自定义名字与说话习惯，以及新手如何花 5 元配好 DeepSeek 密钥或零流量连接本地 Ollama。
接入微信 推荐

不用折腾公众号或第三方破解端，手机微信扫一下码就能连上本机的 TA，出门在外也能随时发消息。
接入 Telegram 与 QQ

通过 Telegram 机器人或 QQ 官方机器人连接本机的 TA；重点注意会话白名单授权，避免配好凭证却收不到回复。

功能与日常使用

桌面客户端使用指南 桌面端

把 Windows 桌面端的五个主栏目、12 类店铺点单与包袋物态、异步回信与拒绝边界、SOUL.md 保护以及无损搬家旅行箱一次讲清。
共读、文稿、相册与节律

详细介绍双人共读、文稿版本对比、双层回忆灯与日记折起、随身包袋嵌套与冷热物态，以及自主拒绝、异步回信与额度控制。
地图编辑器与世界包

怎么一键生成免选风貌的全随机专属世界、切换 7 套内置世界与 4 种主题风格、使用深浅双色离线地图编辑器改建店铺与房间，以及当前的真实工程边界。
常用命令与记忆管理

平时用得最多的几个斜杠指令：看 TA 当前状态、翻看 TA 记住了什么、改掉记错的事，以及随手存备忘。
独立推演与底层服务

在纯命令行或服务器环境下手动开启独立推演建议（/chiyo_consider）、只读世界位置服务与独立文稿工作区的方法。

维护与规划

版本升级与一键回滚

升级只替换程序目录，不动你的聊天记录与人设；万一新版用着不顺手，一行命令就能退回上一版。
数据目录、备份与卸载

搞清楚每个文件夹里装的是什么、怎么停机打一份完整备份、换新电脑怎么迁数据，以及怎样按需干净卸载。
常见问题排查

整理了平时装环境和日常聊天最容易碰到的几个小状况，按症状对号入座就能解决。
已完成与未完成清单

不画饼、不掺水：一页看清当前 v0.8.0 公开测试版哪些已经能用、哪些要手动开、哪些还只是规划。
未来规划：初遇引导与四季 规划

当前公开测试版 v0.8.0 已实装免选风貌的全随机专属世界一键生成、12 类店铺自由点单与无损搬家旅行箱。这里如实写清我们坚守的防打扰边界，以及接下来的零配置初遇引导、跨季节律与世界分享规划。
