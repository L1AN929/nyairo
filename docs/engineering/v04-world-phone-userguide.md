# 世界与身体：体验说明（给操作者，不是给模型）

这台手机现在多了一个「世界」入口：她在某个真实地点、能看见所在房间与街上能去哪、能真的走过去
（在路上，不是瞬移）、能坐下或躺下、能请求开始/停止休息；身体只给姿势、档位和信号，不给数字。
本文只讲**怎么用**和**它会怎样诚实地拒绝**，字段级契约见
`docs/engineering/v04-world-body-contract.md`（C）与 `docs/engineering/v04-phone-api-result.md`（P）。

## 1. 起一个世界体验实例

一次创建（只会创建一次，目录必须不存在或为空）：

```
cd /mnt/d/nyairo-rc1-body-backend
PYTHONDONTWRITEBYTECODE=1 python3 scripts/phone.py prepare-demo \
  --root /tmp/<你的新目录> --with-world
```

`--with-world` 会做三件**真实**的事：用世界包自己的生成器做出住宅与咖啡馆的室内场景与家具；
按世界包自己的声明写下"哪些物件可拿起"；只在这次新建的根里，把"床（作为可休息的床面）"和
"咖啡馆的杯子"摆进身体所在的世界。它不会改任何已有实例，也不会为了提高体验去调整身体阈值。

然后启动（会打印一行 JSON，里面有 `url`）：

```
PYTHONDONTWRITEBYTECODE=1 python3 scripts/phone.py serve \
  --instance /tmp/<你的新目录> --port 0 --tick-seconds 5
```

浏览器打开 `url`，点「世界」。停止：对那个进程 Ctrl-C 或 SIGTERM；它只停自己起的两个 owner
子进程，数据、日志、socket 文件都留在原地（socket 会以 `.retired-<generation>` 保留）。

## 2. 你能看到什么

* **在哪里**：家·卧室（起点），以及"能看到能去哪"：同一栋房子里的客厅/厨房（各 30 秒），
  街上与店铺（真实步时，可能不止一步）。
* **房间里有什么**：世界包声明的家具（床、衣柜、床头灯…）。没有声明室内就是"这个世界没有声明
  室内"，不会拿别处的家具凑数。
* **身上有什么**：手里的物件（左/右手），以及当前地点摆着的东西。
* **身体**：姿势（站/坐/躺）、恢复状态（未开始/进行中/结束/被打断）、以及"身体现在在说什么"的
  档位信号；**没有**疲劳值、体温、血条这类数字。
* **最近的几个动作**：真实账本里的最近几条（成功/失败/原因），来源是"手机上的本地 owner"。

## 3. 你能做什么（每条都会给出确定结果）

| 想做的事 | 会发生什么 |
|---|---|
| 走一段（`MOVE`） | 立刻返回"已出发"，位置**不变**；到时间后由 owner 自己结算到达。界面上会显示"在路上，还剩 N 秒"。一段路就是一段，多步要分几次走。 |
| 拿起/放下（`PICK_UP`/`PLACE`） | 只有世界声明过"可拿"的物件才拿得起；家具拿不起；不在此处的东西拿不到。放下要给它一个合法的落点（房间/某个床面/手里）。 |
| 换姿势（`POSE`） | 站/坐/躺立刻生效，是世界的事实。 |
| 开始/停止休息（`REST`） | 这是**命令**，不是定时器：坐着或躺着才能开始；太不累时会被拒绝并说明"此刻不需要恢复"；开着的时候再开会被拒绝；停止只有在真的开着时才有意义。命令成功 ≠ 已经恢复——下一次读数里的恢复状态才是事实。 |

## 4. 它怎样诚实地拒绝你

* 没绑定本地 owner、Host/Origin 不对、没有 CSRF 令牌 → 直接 403，什么都不做。
* 请求里带了 `uid`/`home`/`authority`/`elapsed_seconds`/`fatigue` 之类 → 409
  `CLIENT_IDENTITY_REFUSED`：这些东西只能由世界/身体自己说，客户端给了也不算。
* 参数不对（少字段、多字段、姿势/朝向/停止方式非法）→ 400，并指出是哪个参数。
* owner 拒绝（不可达、拿不动、手已占、在路上、没床可躺、此刻不需要恢复）→ 409 + 原因码，
  什么都没改。
* 结果未知 → 202；这时**只查原 key**（`GET /api/phone/world/operations/<key>`），不要换一个
  key 重发。同一个 key 只能代表同一个动作：同 key 换目标会被拒（`OPERATION_TARGET_CONFLICT`），
  同 key 换动词也会被拒（`OPERATION_KEY_CONFLICT`）。
* 读世界（打开世界页/看快照）**不会**改变任何东西：不初始化、不发钱、不结算到达、不推进恢复。

## 5. 现在还不能做什么（别把它当成已完成）

* 可拿的小物件不在卧室：worldgen 的住宅里没有"可拿"的物件，所以本轮的杯子在咖啡馆。想在家里
  手边就有可拿的东西，可以先在手机商店买那份"虚拟小点心"（真实扣 240 JPY、真实送到家），
  再拿起/放下它。
* 在咖啡馆没有床，所以只能"坐下休息"，不能"像睡觉那样休息"；睡觉需要家里那张床。
* 恢复要靠 owner 自己的 tick 推进（默认 5 秒一次 tick，但恢复本身每 60 秒才推进一次），
  而且低疲劳时会如实说"不需要"。
* 没做：真实模型自主决定（这些动作是操作者/界面的命令）、真实支付、24 小时常驻、生产部署。

## 6. 个体工具（模型侧）

个体的 `chiyo_phone` 工具新增 `action:"world"`（读）、`action:"world_action"`（显式写，需要
profile 的 `phone.write_enabled`）、`action:"world_operation"`（对账）。它和浏览器走同一条
loopback HTTP、同一套闸门；动作会记成"模型发起"，不会冒充她自己的决定，也不会在失败时换 key
重试。
