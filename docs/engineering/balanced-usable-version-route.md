# 均衡可用版：先把现有能力连成生活

**判断：身体、虚拟世界最接近可用。下一块优先让她围绕真实作品持续做事，身体、世界、动机和记忆一起参与，不再各做一个孤立演示。**

## 身体
现在：她能坐、站、移动和休息，身体资源会随姿态、环境和时间变化；已经实际自主坐下完成过。
离别人能用还差：在普通使用中让负荷、休息、恢复与继续做事连贯发生，避免看起来有身体、选择却长期与身体脱节；不强迫吃睡或休息。
最省顺序：保留现有六变量，先在同一个作品活动中贯通身体影响与后续选择，再调明显失真的反馈，不先扩营养或新生理系统。

## 虚拟世界
现在：她能在地点间走动，完成多段旅程，拿放物件、改变姿态，读材料和保存作品；作品有版本与历史，世界有随时间变化的环境事件。
离别人能用还差：给出一套明确可启动的房间、材料与作品入口，让人知道怎样提供内容、观察结果和下次继续；已有能力不要散在开发命令里。
最省顺序：先统一启动与使用入口，围绕一件真实作品串起阅读、续作和有用途的世界动作，再逐步增加场景，不先铺更多手机应用。

## 欲望／自主选择
现在：她能提出稍后事项、把已有事项排进今天、选择作品或研究机会，也能暂停、换事或不做；这不是已经完成的独立欲望系统。
离别人能用还差：让自己的疑问、作品进度、试过的做法和结果在后来形成有意义的选择，而不是反复只在阅读、姿态和安静间打转；不能靠强迫活跃解决。
最省顺序：先围绕同一作品，把真实结果带入下一轮，允许她采用、评价、修改或不用一种做法，再接回作品历史与有限本地表达；不要另造一个欲望总脑。

## 记忆
现在：经历能保存、被后来读取，作品结果能作为方法评价依据，删除在当前读取中能扣留；但跨备份恢复防复活还没修完。
离别人能用还差：普通重启后能继续原作、读回此前做法与结果，并让它们实际影响后续决定；删除后的恢复不能把内容带回来。
最省顺序：先随作品主线做好有用的回忆与接续；V-C作为一块有界修复完成，不扩成基础设施项目。离线控制记录只能在不随业务一起回滚、且能确认足够新的条件下保护恢复，不能宣传成任意整盘回滚都安全。

**最短交付顺序：收好在途AI手机读取 → 一块“同一作品持续生活”（结果影响做法与下一步，连历史与本地表达）→ 有界完成V-C → 统一启动与使用说明，做一轮整版检查后交别人用。**

日常开发只确认这块功能实际能用；完整发行检查集中到发版前。没有新增真实模型花费、删迁数据或产品规则授权。
