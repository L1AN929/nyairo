# NyAiro v0.3「后端连续生活版」对比 GitHub v0.2

## 一句话

**0.2已经能自主做一些事；0.3把出门、等待、改主意、消费、留下经历、回家续自己的事，接成了有真实后果、可以暂停和恢复的连续过程。**

当前是本地已限定验收的v0.3候选，功能施工已停止。未提交、未打标签、未推送GitHub、未打包/部署。不是完整CHIYO总体设计，也不是最早Web工作台提案全交付。最终测试见 [验收报告](v03-final-acceptance.md)。

- `docs/v02-baseline.md`记的是早期251e920施工前状态，**不作为rc3最终能力**。本比较核对了发布树及其中`v02-autonomous-life-implementation.md`等交付说明。

## 2. 0.2已有的东西，不能冒称0.3首次实现

rc3已有自主常驻cycle、模型决策与作品内容、Supply版本/CAS续写、Memory准入、World真实位置变化与单段步行计时。底层也已有世界包、WorldGen/编辑器、Body、Activity/Action/结算等owners。

0.3复用它们，不是重写一套世界/记忆/人格系统。rc3还有真实模型跑通部分旧链的记录；**本次v0.3新增链全部用替身/本地loopback验证，尚不能把旧记录冒用于新链的真实模型表现**。

## 3. 主要更新

| 领域 | 0.2 rc3 | v0.3新增或增强 | 用户能感受到的差别 |
|---|---|---|---|
| 去哪里 | 工具偏固定汐见市别名和nearby_street中转 | 从活动世界图解析动态地点/唯一名称/室内区域、选真实路线；歧义/不可达明确拒绝 | 换世界或进室内，不再靠硬编码猜中转；不知道就不乱走 |
| 多段出行 | 有真实单段移动与走时 | 持久journey记录最终目标、段、execution/travel身份与进度，逐段到达再续行 | 不是说一句“我到了”；中途停下或重启还能知道走到了哪一段 |
| 后台推进与暂停 | 后续main有粗心跳原型 | 正式runner/单写者租约/状态只读；暂停挡新段，已经出发的一段允许如实到达 | 暂停是真的停新行动，不是隐藏画面；恢复不会把已走的路再走一遍 |
| 超时与丢回执 | 旧链已有UNKNOWN/结算基础 | 客户端提交一次，同execution查owner；journey未知不误判终态，落账后认领 | 没收到答复不等于没做，也不因重试做两次；没证据就继续承认未知 |
| 请求安全与预算 | 已有轮次计数和调用路径 | decision/content/schema retry发送前逐次持久预留；UTC日/本次窗口双上限，不退款不靠重启洗额度；发出锁与暂停同边界，等待响应不持锁 | 暂停确认后不会继续偷偷启动请求；服务卡住时不把控制一起锁死 |
| 私人事项与阅读 | 以作品/活动为主要载体 | 备忘、收藏、来源取得、阅读位置、未懂、收件等typed事项，仍存真实Supply版本 | 可以保留自己的小事；收藏不冒充已获取，翻到某页不冒充读懂 |
| 被打断后接着做 | 具备Activity与continuation基础 | 有限共同时间安全中断、原checkpoint/恢复资格保留、回家合法RESUME再CONTINUE | 陪伴/出门后能接回原来那件事，不是每轮重新开一件 |
| 有限街区生活 | 已有世界包/位置/规则和移动 | 六地点街区、局部有来源机会、MOVE/CONSUME/非产出STAY进正式生活链 | 可以去公园坐会儿、遇闭店改变选择、回家；不要求每次行动都产出作品 |
| 消费真实后果 | 无本版CONSUME合同 | 可持有或明确免费的当前可达consumable，一实例一份，原子耗尽+可归因receipt，Body恰一次轻操作 | 吃掉的那一份不会自动复活；未授权/经济事实损坏会拒绝，不假购买 |
| 停留结束与改主意 | 未具备本版有界停留链 | 未到时不能完成；自然待满与合法提前ABANDON分开；关门后不能继续造在场checkpoint | 坐一会儿可以中途决定走，但不会把三分钟记成待满五分钟 |
| 经历影响以后 | 已有M0准入 | World后果走既有handoff准入，文案不冒作品修改；真实经历进入后续请求并改变合法选择，空/弱历史有负控 | 不是仅写一句日记；发生过的事能真正改变下一步，同时回忆不变成授权 |

## 4. 这版实际验证过什么

最终8组、**51个选定检查通过，0跳过**；不是全仓所有测试通过声明。覆盖动态导航、发送/预算、私人处境、消费权限与恢复、营业预期、owner真新PID恢复和丢回执、同实例街区连续生活、Memory因果与Life新runtime恢复。

一条代表链：自己的作品落真实版本 → 合法中断保存 → 出门 → 公园自然停留 → 看到咖啡店关着先不去 → 开放后去坐 → 关门主动结束（未待满不假完成）→ 阅读点 → 回家 → 恢复原checkpoint继续出新版本。本次World经历也真的进入M0和后续输入。

主链10条正时长边共声明1320s，但采用加速/显式时钟与owner到期结算，不是真实过完一天。真实本地owner≠真实产品模型。真实新PID恢复≠生产整套驻留服务部署验收。

有过的红灯均留证：owner丢回执测试屏障抢在真实提交之前，已改为落账后认领；最终父级保留式runner误留活动WAL导致两组红，修runner后只复验这两组，产品未改。最终冻结的54个产品/数据成员及3个组件测试成员字节一致。详见验收报告，不把失败历史擦成全绿。

## 5. 明确没做完的部分

- **没有统一Web生活/模型配置工作台**。原官网、世界编辑器与项目看板，不等于绑定当前实例的生活控制台；本版不把早期Web提案标完成。
- **没有新增链路真实模型一天/24h稳定性证明**；没有生产部署、打包安装/迁移或公开release验收。
- **Future/Agenda生活接线未做**：只读营业预期已提供，但明确认领、持久议程到期、重新考虑的整条产品链后置；F-096/F-097不算全完成。
- **没有营养/饥饿/饱足/恢复系统**：消费只带既有2秒轻操作后果，不凭“吃了”宣称健康改善。
- Body仍只有LIMITED/UNKNOWN的有证据映射，正向AVAILABLE事实未证；生产S07评价源未具备，消费者不假装完整情绪系统。
- 停留PAUSE没有暂停区间扣除后的计时恢复；area级停留、真实并发多前台、NPC自主社会、外发/支付、长期Skill/迁移等不在本版。
- 不是193功能全部完成；旧blocked journey不自动解冻/迁移，正式travel回执有墙钟耦合等边界仍披露。
