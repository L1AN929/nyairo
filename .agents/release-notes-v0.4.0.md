## v0.4.0 · 连续生活闭环

从 v0.3 的「单段旅程 + 单次暂停」推进到「一天里能连着过」：出门可以分多段走完，暂停的事情可以堆着等，世界的天气与事故会跨天延续。

### 生活闭环

- **多段旅程**：一段旅程拆成多段，每段独立消费一张票。实测跑通 卧室 → 客厅 → 街上 → 书店 的连续四段出门。
- **多挂起单执行**：PAUSE 释放前台，同时保留显式等待条件，可以同时挂起多件事；任何时刻只有一件在执行。
- **条件满足后回来**：挂起事项在条件成立后回到候选，按「新 head / 同 head / 读失败」三组分别验证。
- **跨段许可**：前一段的许可不再被后一段无条件继承，授权边界按段结算。

### 身份与观测

- BODY 动作 key 纳入已提交 Decision，不再跨活动串用同一个 Action。
- 拒绝不再退化成 UNKNOWN；`owner_evidence` 区分「未写成」和「未知」两种失败。

### 世界

- 环境事件分三档；v2 支持有限的跨天事件：固定身份、有阶段、到期不复活。
- 世界包 schema 扩展，用于承载事件与后果。
