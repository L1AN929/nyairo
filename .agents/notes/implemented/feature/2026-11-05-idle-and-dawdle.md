# Agent Note: 给她一些产出为零的时间

Status: implemented

> 2026-11-07 后续裁定：发呆/闲逛的轮换候选项保持不变；但「地点没有已知 affordance 时
> 退回 QUIET_STOP」的旧兜底已被
> [strict-activity-definition](2026-11-07-strict-activity-definition.md) 替换为明确报错/
> 零候选。本笔记的 idle 轮换决定本身未被翻转。

## Problem

2026-11-05 的 Z 批她过完了完整的一天：起床、读自己的材料、出门、进书店、读完一本书、写批注、回家，
20 个请求全部花在"有用的事"上。用户的评价是"感觉她没有像人一样生活"。

数据支持这个判断：20 次决策每一次都在推进一个有完成条件的活动，中间没有一次是"在街上站了一会儿"
"回到家坐着发呆""翻了翻桌上的东西没意思又放下"。而且家这个地点原本只有 `REST` / `READ` /
`USE_PHONE` 三个选项，全是需要产出或有明确目的的——家里连一个"什么都不干"的选项都没有。

更麻烦的一层在机制上：`STAY_DESCRIPTOR_PREFERENCE` 让**一个地点只按优先级挑一条** affordance
生成停留候选。所以即使往表里加"发呆"，只要它排在 `REST` 后面，就永远轮不到，加了等于没加。

## Decision

把停留拆成两层，互不竞争：

1. **地点自己的正当选项**照旧按偏好表挑一条生成候选，行为不变。书店仍然只有
   `stay:<place>:READ_HERE:600`，发呆挤不进去。
2. **"什么都不干"作为独立的一条候选**，与正当选项并列出现，按 `observed_at` **每小时轮换**一条。
   三条：`DAZE`（发呆，180 秒）、`POTTER`（在屋里转转，180 秒）、`PEOPLE_WATCH`（看人来人往，180 秒）。
   候选标签说日常话，例如"在临海的住居发会儿呆"；中性描述是"随便转转"和"站着看看人"。
   [idle2独立观察入口](../testing/2026-11-06-idle2-bounded-observation.md)承接这组呈现，不把NO_ACTION改成停留，也不承诺自然采用。

世界模板相应给 `fixed_slots.home` 加了 `DAZE` / `POTTER`，给 `street` 和 `park` 加了
`PEOPLE_WATCH`；`STAY_TITLES` 补三条口语标题，兜底文案从"在一个地方待一会儿"改成"在这儿待一会儿"。

## Alternatives considered

- **把 `DAZE` 插到 `STAY_DESCRIPTOR_PREFERENCE` 最前面。** 最强立论：改动最小，一行就能保证它出现。
  否决原因：那会让她每次在家都发呆，是拿"只有发呆"换掉"从不发呆"，两种都不像人。人要的是有事做事、
  没事才发呆，所以它必须与正事并列、由她自己选，而不是抢占正事的位置。
- **只把兜底文案改口语，不加新候选。** 最强立论：零风险，不碰候选生成。否决原因：她现在缺的不是措辞，
  是真的没有可选的"浪费时间"，改文案只是把同一件事说得亲切一点。

## Consequences

- 她任何一个钟点都能在候选里同时看到"一件正事"和"一条无所事事"，选不选由她。
- 读书位不受影响：反向用例连扫 8 个钟点，始终只有一条 `stay:reading_point:READ_HERE:600`。
- 轮换有测试咬住：`test_the_idle_options_rotate_in_over_three_consecutive_rounds` 断言三轮的
  idle 描述符集合是 `{DAZE, POTTER}`；把轮换钉死后该断言会红，说明不是空转。
- 未验证的是最要紧的一环：**她会不会真的选**。这一单只保证选项存在且轮得到，一次真实运行都还没跑。
  如果加了之后她仍然次次挑正事，那问题就不在选项上，得往"她为什么闲不下来"那边查。
