# 独立运行与数据边界 · 0.4.0

本轮只升级本地世界编辑器与隔离测试后端。未修改、部署或调用生产 nyairo、Hermes、World/Life/记忆、私人角色或正在开发的网页版。

实际链路：浏览器 → 本机 server.py → Store / model.py / space.py / resources.py → 指定目录 SQLite。只有程序本机 HTTP；没有模型、账户、素材平台或云请求。

草稿保存场景与初始规则、完整素材库。新试运行冻结启动时的世界包，SQLite 中单独保存居民实际位置、路径、门状态、物件/身体/时间/事件。图像资源是内容，杯子空满与消耗份数是运行状态，二者分开。同图多个实例各有状态。

所有动作在后端检查当前状态，计算下一状态并校验，SQLite 在一次事务中提交状态和动作回执；失败不提交部分结果。请求带试运行版本和唯一执行 ID。旧请求冲突，同 ID 相同请求仅重放回执，返回当前状态；不会再次喝水、装水或倒退居民经历。前端仅提交命令并显示服务返回结果。

创作撤销、图片替换、墙壁修改、导入世界不修改已有试运行。试运行中的门状态不会写回草稿初始门状态。居民存档恢复创建新实例，世界导出不含居民经历。

世界包 v3 / editor-runtime.v3 是独立工具的接口声明，不能据此认定生产 nyairo 已支持。没有生产导入入口、Hermes 适配或旧个人世界覆盖操作；请勿把编辑器 SQLite 或存档替换为生产个人存档。

服务只监听 127.0.0.1，验证 Host/Origin/请求标记，静态文件固定白名单；图片限定静态安全格式，SVG 不内联为可执行页面。应用数据留在指定本机目录。
