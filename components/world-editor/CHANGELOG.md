# 更新记录

## 0.4.0 · 2026-10-11

- 从 v0.3 完整源码升级，保留原区域连接、编辑历史、恢复和保存事务。
- 新增空间模式：正交墙、依附门窗、矩形地面，局部 5% 吸附、长度/颜色/纹理/素材属性、复制/级联删除与辅助层。
- 新增后端 20×20 路径搜索和居民网格坐标；墙/窗/关闭或锁定的门实际阻挡，开门恢复；区域旅行检查入口路径。
- 新增静态 PNG/WebP/受控 SVG 素材、集合/分类/搜索、点击和拖入、共享引用、默认视觉与交互开关；导出仅嵌入实际使用资源。
- 杯子空满、装水设备可用性、灯开关、门开关/锁定接入真实状态；空杯装水/喝水消耗份数、时间和身体值，失败原子拒绝。
- 世界/存档升 v3，兼容真实 v1/v2；旧数据库迁移保留时间、经历、ID、回执，补默认位置和状态。
- 增咖啡馆示例及实际从空白创建的验收世界、测试和截图。
- 适配图片恢复体积、扩大历史快照预算，关闭标签页/取消下载不产生响应写入堆栈。

## 0.3.0 · 2026-10-11

- 增加缩放、平移、网格开关/吸附、框选、多选、群组拖动、复制/粘贴/副本、对齐/等间距、批量主题/尺寸与右键菜单。
- 区域尺寸支持画布控制点和键盘；连接支持画布两点创建、选择、调整端点和删除。
- 新增四个区域主题、地板纹理/颜色、标题背景、边框样式和场景设置。
- 统一七种内置 SVG 物件，支持尺寸、朝向、层级、名称开关、放置预览及无辅助线场景预览。封面复用相同素材。
- 行为卡片读取后端模板；阅读/休息分钟、精力变化、饮品水分配置接入实际执行与存档。
- 开放时间保留跨夜规则，增加指定时间预览；明确关闭时的进入/使用限制。
- 居民按真实状态显示站立/坐下/躺下、持有物、家具占用、份数和柜内数量，支持自选等待分钟。
- 新增空白世界、对象搜索、可折叠侧栏和首次操作引导；改进保存/导出/错误状态。
- 世界包和存档升为 v2，支持 v1 校验升级；旧数据库迁移不重建居民状态或回执。
- 浏览器恢复副本增加 SQLite 镜像和写入序号；完成真实浏览器关闭、服务重启后的恢复及旧副本冲突验证。
- 新示例实际使用主题、旋转、尺寸、21 分钟阅读和 45 分钟休息；保留 v1 样本。
- 新增布局、视觉/行为、兼容迁移、规则预览和恢复写入测试。完整验证见 TEST_REPORT.md。
- Windows 启动器先检测可用的 Python 3.10+，再尝试 py，避免失效的 py 注册路径挡住已有可用环境。
