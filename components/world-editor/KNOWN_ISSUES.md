# 已知问题与范围 · 0.4.0

- ZIP 不含 Python，不是单文件 EXE；需要已有 Python 3.10+ 和现代浏览器。
- 室内是每个区域 20×20 的四邻接网格。墙仅水平或竖直，地面仅矩形；通过多段墙可绘制走廊和不同轮廓，不支持斜墙、自由多边形或 3D。
- 墙阻挡移动；窗始终阻挡；门仅开启时允许穿过其跨度。墙不接到边界时可以绕行，这属于实际布局结果。没有多区域连续物理地图：区域连接仍是独立旅行。
- 路径由后端搜索并计时，每走一格推进一分钟，精力消耗为步数除以十向上取整。画布显示当前位置和实际路径，当前没有逐格行走动画。
- 家具图片大小/旋转/层级只影响视觉。家具不会作为碰撞障碍，居民可经过其网格；接近条件、坐卧占用、持有、储物规则真实执行。
- 只有单个手动测试居民，规则不是任意编程。有限模板有固定物件/状态条件，不能配置多角色、任意变量、用户脚本、复杂蓝图或模型决策。没有 AI 自主生活、Hermes/生产接入、云账号、同步和工坊。
- 单图最多 512 KiB、每边最大 2048 像素；每个草稿最多 32 张，原始图像合计最多 3 MiB。只支持静态 PNG、WebP 和受控 SVG。SVG 的 style、image、use、外部字体/资源、脚本、事件、动画、foreignObject 等会拒绝；需转为 PNG/WebP 或导出为简单路径/颜色属性。
- PNG/WebP 后端检查文件容器、尺寸和静态限制，不做完整位流解码；图片导入面板还需浏览器成功解码才能加入素材。手工构造的 JSON 包可能含通过容器校验但浏览器无法显示的损坏图片，应从素材导入面板更换。
- 图片内嵌 JSON，素材集合是本地分类字段；没有独立素材集合包或素材删除界面。世界导出自动剔除未使用图片，本地草稿仍保留完整库。地面图片拉伸铺满分区，不提供复杂 UV 或裁切。
- 保存与世界导入文件上限 8 MB；HTTP 请求上限 18 MB，为恢复副本连同基础指纹留空间。浏览器存储容量可能不足，本机服务镜像仍可保存；最终看「本机恢复副本已更新」确认。
- 最后修改尚未得到本机确认就终止服务，不能保证恢复。恢复副本不代替停服务后的完整 data 备份。已恢复/另存的旧副本可能继续显示，「暂不恢复」不删除；没有副本清理或自动合并冲突。
- 撤销限当前页面、最多 40 步及约 32 MB 快照预算；图片较多时会提早淘汰旧步骤。重新打开不恢复历史，也不会回退居民经历。
- 下载被浏览器取消时，从 data/exports 取真实文件。本机自动化浏览器使用该文件完成第二实例上传；没有把下载按钮点击当成文件下载成功。
- 手机支持操作、无页面横向溢出；详细创作推荐电脑。双侧列表可能较长，可以折叠和搜索。
- 实际验收环境是 Windows、Python 3.13.15、Node 22.19.0、自动化 Chromium；另一实例使用同一台电脑的独立空数据库。Python 3.10 和其他浏览器/物理设备未单独运行验证。
- 旧 v1/v2 世界默认关闭室内空间，以保留旧版可操作性。主动启用空间会增加坐标移动，需重新创建试运行；旧存档新增入口坐标不会臆造历史步行轨迹。
- v3 无反向降级导出；回退旧程序必须恢复升级前数据备份。ZIP 不含验收数据库，首次启动创建独立数据。
