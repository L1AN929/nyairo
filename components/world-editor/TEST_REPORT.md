## Windows ZIP 发行验收

发行根目录为 nyairo-world-editor，包含完整源码、教程/格式/边界/限制/报告、示例、测试和 7 张真实截图，共 47 个文件。排除 data、所有 __pycache__、pyc 和 Git 目录。ZIP 完整性检查和逐文件与交付源码比对通过，不携带任何 QA 居民数据库。

从 ZIP 解压到独立目录，实际运行 start.cmd（电脑已有 python，未用失效的 py 注册路径）。服务器监听 127.0.0.1:8766，首次创建 revision=0 的独立 SQLite，显示午后咖啡馆和自定义柜台图片。

在解压程序页面重新执行拿空杯→走到门旁→开门→跨墙到设备→装水→喝水。默认示例装水为 2 分钟，整个操作链共 15 分钟，杯归零、居民水分 80；导出居民存档得到实际文件，浏览器错误列表为空。另在最终重新打包后再次解压启动，保持源码与 ZIP 完全一致。
