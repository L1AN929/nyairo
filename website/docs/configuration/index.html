日常启动、人设与模型

平时怎么唤醒 TA 聊天、怎么自定义名字与说话习惯，以及新手如何花 5 元配好 DeepSeek 密钥或零流量连接本地 Ollama。

平时怎么打开聊天

  • Windows 桌面端：双击桌面快捷方式或点开右下角托盘里的猫咪图标即可。按 Ctrl + K 可以随时呼出快捷操作栏，切换界面或发起新对话。
  • Linux / WSL 终端：打开终端输入一行 nyairo 回车就能开聊；聊完输入 /exit 或按 Ctrl + D 退回命令行。

修改名字与人设 (SOUL.md)

TA 叫什么名字、平时怎么称呼你、说话简洁还是细腻，都写在个人数据目录的 SOUL.md 文件里。用任意文本编辑器或终端自带的 nano 打开就能改：

bash
nano "$HOME/.nyairo/SOUL.md"

不需要写复杂的提示词套路，像写人物小传一样用自然中文写清楚这三点就够了：

  • 名字与关系：TA 的名字，以及你们平时以什么身份相处（朋友、室友、搭档等）；
  • 说话习惯：口吻偏安静克制还是轻松随性，喜不喜欢长篇大论；
  • 基本默契：认真对待聊过的约定，不知道的事如实说不知道，不硬编；不想应承的忙也可以自然说不。

在 nano 里改完后，按 Ctrl + O 回车保存，再按 Ctrl + X 退出，重新进入对话即生效。

新手零门槛教程：5 元 DeepSeek 密钥与免费本地 Ollama

nyairo 本身不卖算力、也不抽成：空间寻路、冷热物态与权限都由本地确定性骨架驱动，不需要额外花钱调「裁判大模型」。完全没接触过 API 的新手，按下面两条路线任选其一，三分钟就能配好：

路线一：花 5–10 元开通 DeepSeek API Key（推荐轻薄本用户，无需独立显卡）

  1. 浏览器打开 DeepSeek 官方开放平台 platform.deepseek.com，用手机号注册并登录；
  2. 点击左侧菜单「充值」，充入 5 到 10 元人民币（日常聊天一句话只消耗几厘钱，5 元足够日常聊上好几周，且桌面端默认自带每日 50,000 Token 用量封顶保护）；
  3. 点击左侧菜单「API keys」→「创建 API key」，名称随意填（如 nyairo），立刻点击复制生成的以 sk-... 开头的密钥串（关掉弹窗后网页不再显示完整密钥，请妥善保存，切勿发给他人）；
  4. 打开 nyairo 桌面客户端，点击左侧「设置 → 模型」（界面对应「模型与通道」卡片）：
    • 服务商选择 DeepSeek（Base URL 为 https://api.deepseek.com）；
    • 模型名称填写 deepseek-chat；
    • 将刚才复制的 sk-... 密钥粘贴进 API Key 输入框，点击「保存配置」，再点旁边的「测试连通」，看到返回毫秒级响应耗时就配好了。

路线二：免费连接本地 Ollama（适合有闲置内存或显卡、希望零云端流量的用户）

  1. 前往 ollama.com 下载并安装 Ollama，打开系统终端拉取一个中文表现均衡的本地模型（16 GB 内存电脑推荐 7B，8 GB 内存可选 3B）：
    bash
    ollama pull qwen2.5:7b
  2. 确认 Ollama 服务已在后台启动（默认监听本机 http://127.0.0.1:11434）；
  3. 打开 nyairo 桌面客户端「设置 → 模型」（或在终端运行 nyairo setup model）：
    • 选择 Ollama / 本地兼容接口，接口地址填 http://127.0.0.1:11434/v1（Ollama 原生服务地址为 http://127.0.0.1:11434）；
    • 模型名称填刚才拉取的 qwen2.5:7b，API Key 栏随意填 ollama 占位即可；
    • 点击保存并测试连通。此后所有对话推理、长期记忆与日常节律 100% 在你自己的电脑闭环运行，零云端流量、零账单开销。

切换模型或更换 API Key

以后想换用别的模型（比如在 DeepSeek、Claude、OpenAI、Qwen 或本地 Ollama 之间切换），或者更新过期的 API Key：

  • 桌面端用户：直接在左侧「设置 → 模型」面板里修改模型供应商、模型名称与 API Key，点保存并测试连通即可（密钥只写入本机 0600 权限配置，界面不会明文回显旧密钥）。
  • 终端用户：在命令行运行：
bash
nyairo setup model

换模型不会影响已经攒下的聊天记录、房间物态和长期记忆。
