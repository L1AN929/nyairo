已完成与未完成清单

不画饼、不掺水：一页看清当前 v0.7.0 公开测试版哪些已经能用、哪些要手动开、哪些还只是规划。

本页目录（4 节）▾

  • 需要手动开启或配置的功能
  • 有意保持的边界与尚未完成的规划
  • 发行包来源与验证说明

已经跑通、直接可用的功能（v0.7.0）

  • 双层回忆灯与本地长期记忆闭环：跨会话自动沉淀重要事实进本机 SQLite，双层回忆灯严格保护原始记录零篡改，支持 /chiyo_memory list 查看、correct 纠错与 delete 停止召回。
  • 连续出行、12 类街区店铺与包袋物态：支持多段路网寻路、真实步行计时与断点续走；覆盖 12 类街区店铺与开放柜台自由点单（如去便利店买热关东煮），旧书店与咖啡屋店主独立错峰作息与吧台杯垫留言；随身包袋最多 3 层嵌套收纳，具备热茶放凉、窗边纸条遇雨微潮晕字等冷热干湿物态。
  • 免选风貌全随机专属世界、7 套内置世界与深浅双色离线编辑器：除海滨「凪浦」（凪读作「止」zhǐ）、温泉「汤川」、田园「穗村」、街区「栞泽」（栞读作「刊」kān）等 7 套世界与 4 种主题风格外，支持免选风貌的全随机专属世界一键生成（6 种地貌混搭、4 种异构路网、8 类商业店铺与多房间住宅）及深浅双色离线可视化地图编辑器。
  • 去工具人化拒绝边界、异步回信与无损搬家旅行箱：不想帮的忙干脆拒绝，不念客服式道歉模板也不记仇；按真实日程隔几小时异步回信，睡眠/外出/专注时将非急事收入手机待回匣，真急事可敲门找 TA；支持导出 .nyairo-suitcase.zip 无损搬家旅行箱连同世界切片与迁移损失清单整套带走。
  • 相册、双人共读与文稿对比：支持旅途相册查看、导入读物或示范书同步记录页码批注，以及文稿多版本历史快照与差异比对。
  • 多端入口：提供免管理员 Windows 原生桌面端（nyairo-0.7.0-setup.exe）、Linux / WSL 命令行，支持手机微信扫码直连与 Telegram 机器人绑定。
  • 平滑升级与回滚：支持 nyairo update 整包更新与 --rollback 保留新聊天记录回退。

需要手动开启或配置的功能

  • 大模型接口配置：框架不捆绑售卖算力，可花 5–10 元配好 DeepSeek API Key，或直连免费的本机 Ollama（http://127.0.0.1:11434，见 新手零门槛模型教程）。
  • 后台无人值守自主活动：默认关闭（避免后台悄悄跑流量费），需要体验「你不找 TA 时 TA 自己散步写随笔」可在设置或命令行加上显式开关并设好预算上限（见 共读、文稿、相册与节律）。
  • 本地相机拍照生图：需用户自行在本机启动 Stable Diffusion WebUI（127.0.0.1:7860）与本地提示词转换服务（127.0.0.1:18190），未启动时如实提示不可用。
  • /chiyo_consider 独立推演：默认关闭，按 独立推演与底层服务 修改两行配置即可开启。
  • QQ 官方机器人私聊：除填写 AppID / AppSecret 外，需在会话白名单中放行对应的 qqbot 私聊标识（见 QQ 接入说明）。

有意保持的边界与尚未完成的规划

  • 无交互时不主动向微信 / Telegram 弹窗推送（有意保持的防打扰边界）：虽然支持手机待回匣异步回信与后台自主起居，但不会在未交互、未约定前提下主动往微信、Telegram 或 QQ 推送消息打扰你。
  • 后台自主生活经历不支持直接改写正文（真实性边界）：对话记忆可通过 correct 纠正，但后台自主生活沉淀的经历仅支持 delete 停止后续召回，不支持直接篡改正文。
  • 首次启动零配置初遇向导、跨季节物候与世界工坊（规划中）：全随机专属世界一键生成与无损搬家旅行箱已就位；首次打开免点选的沉浸式初遇向导、更深层的跨季节物候节律以及社区世界包分享仍在后续路线图中（见 未来规划）。
  • 不做生存数值游戏与物理磁盘粉碎：当前的休息与补给只是四档轻量日常节律，关机不倒扣惩罚；/chiyo_memory delete 的作用是停止后续检索召回，原始会话日志与历史备份仍保留在你的本机磁盘上。
  • macOS 与 Docker 整包方案：尚未完成独立打包与全流程验证。

发行包来源与验证说明

当前公开测试版源码与校验压缩包均发布在 GitHub Releases v0.7.0，Windows 桌面安装器由官网同源分发并附 SHA256 校验文件。历史版本（v0.6.0、v0.5.1、v0.4.0、v0.3.0、v0.2.0-rc3 等）保留原样供对比或回退。各版本具体跑过哪些测试、没跑哪些测试，详见 测试范围与发行说明。
