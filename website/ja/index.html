このマシンに nyairo v0.7.0（オープンソースの AI 個体フレームワーク）をインストールしてください。各ステップの実行前に内容を簡潔に説明し、検証手順を絶対に省略しないでください。

[参照情報]
- 公式リポジトリ: https://github.com/L1AN929/nyairo
- 対象リリース: v0.7.0 のみ（未検証ブランチや古いタグは使用しないこと）

[Step 1: 事前環境チェック — まだインストールしないこと]
以下を確認して報告してください:
1. OS とアーキテクチャ（Linux / WSL 2 / macOS / ネイティブ Windows）および bash・curl の有無
2. Python 利用可否（bootstrap 時に uv 経由で Python 3.13 を構成します）
3. 空きディスク容量（3 GB 以上推奨）
4. github.com および astral.sh への疎通
5. $HOME 内の既存環境有無: ~/.nyairo, ~/.local/share/nyairo, ~/apps/nyairo-*, ~/.local/bin/nyairo
6. 稼働中プロセス: pgrep -af m0_writer_worker, pgrep -af "gateway run", pgrep -af nyairo
WSL のないネイティブ Windows の場合は公式デスクトップ版（https://nyairo.com/downloads/nyairo-0.7.0-setup.exe）を案内して停止してください。既存環境が見つかった場合も上書き防止のため即座に停止し、無断でプロセス終了や sudo を実行しないでください。

[Step 2: 配置パスの確認]
本体は ~/.local/share/nyairo/releases/v0.7.0、個人データは ~/.nyairo、起動コマンドは ~/.local/bin/nyairo に配置されることを説明し、私の確認を待ってください。

[Step 3: SHA256 検証付きインストール]
1) リリースアーカイブと SHA256 の取得・検証:
   curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.7.0/nyairo-v0.7.0.zip
   curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.7.0/nyairo-v0.7.0.zip.sha256
   sha256sum -c nyairo-v0.7.0.zip.sha256
   一致しない場合は直ちに中断すること。
2) 展開と公式 bootstrap の実行:
   python3 -m zipfile -e nyairo-v0.7.0.zip "$HOME/apps/nyairo-v0.7.0"
   cd "$HOME/apps/nyairo-v0.7.0" && bash scripts/bootstrap.sh --no-setup --no-launch

[Step 4: 導入後セルフチェックと引き継ぎ]
~/.local/state/nyairo/install.json が v0.7.0 であることを確認し、scripts/verify_manifest.py（"valid": true）と ~/.local/bin/nyairo -z "install self-check" を実行してください。最後に私自身で `nyairo` および `nyairo setup model` を実行する手順を案内してください。チャット欄に API キーやパスワードの入力を決して求めないでください。

高性能な GPU（グラフィックボード）がなくても快適に動きますか？
はい、不要です。DeepSeek・OpenAI・Claude・Qwen などのオンライン API を使う場合、推論計算はクラウド側で行われ、手元の PC では約 5.8 MB のデスクトップクライアントとローカル SQLite 記憶帳簿だけが動きます。内蔵グラフィックスの一般的なノート PC でも静かに常駐します（ローカル Ollama モデルを手元で動かす場合のみ PC 側の性能を使用します）。
会話内容や SOUL.md、長期記憶が外部サーバーへ送信されることはありますか？
一切ありません。nyairo 運営側の中央サーバーやテレメトリ収集は存在せず、SOUL.md・会話履歴・二層メモリーランタン・共読原稿はすべて手元の PC 内の ~/.nyairo にのみ保存されます。通信先はあなたが設定した API エンドポイントまたは連携チャネルだけであり、ローカル Ollama を選べば 100% オフラインで完結します。
全員が同じ街に住むのですか？自分の街を作ったり編集したりできますか？
7つの内蔵街（海辺の凪浦、温泉街の湯川、水車の里の穂村、街角の栞沢など）をいつでも切り替えられるほか、テンプレート不要の完全ランダム専用ワールド生成で自分だけの街をワンクリック合成できます。さらにオフライン視覚マップエディタで壁・扉・家具・営業時間を描き、パックとして書き出すことも可能です。
利用料金や月額サブスクリプション、アカウント登録は必要ですか？
nyairo 本体は Apache-2.0 の完全無料オープンソースです。アカウント登録・月額課金・トークン中抜き手数料はゼロです。ご自身の API キー（DeepSeek なら数百円のチャージで長期間利用可能）を貼り付けるか、無料のローカル Ollama を指定するだけで使えます。自律起床も初期オフ・日次上限付きで安心です。
一般的な AI チャットアプリやロールプレイ画面と何が違うのですか？
閉じた瞬間に時間が止まるテキスト枠とは異なり、道路グラフ・部屋の間取り・温度や湿度の物性がローカルで連続して動いています。コンビニや古書店へ歩くには実際の分数がかかり、移動中の雑談はスマホの返信トレイに保留され、机の温かいお茶は自然に冷め、無理な代筆依頼は定型謝罪なしで対等に断ります。
アプリを更新・アンインストールすると、これまでの記憶は消えてしまいますか？
消えません。読み取り専用の実行プログラムと個人の記憶データ（~/.nyairo）は厳密に分離されています。Windows デスクトップ版をアンインストールしても WSL 2 側の記憶データベースは無傷のまま残り、CLI の nyairo update --rollback や API キーを自動除外した .nyairo-suitcase.zip によるロスレス引越しにも対応しています。
