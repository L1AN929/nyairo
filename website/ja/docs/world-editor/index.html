マップエディタとワールドパック

テンプレート選択不要の完全ランダム専用ワールドのワンクリック生成、7 種の内蔵ワールドと 4 種のテーマスタイルの切り替え、ライト／ダーク両対応オフラインマップエディタを使った店舗や部屋の改築、そして現在の実装上の境界線について解説します。

同梱の 7 種のワールドと 12 業種の街角ショップ

初回インストール時のデフォルトワールドは海辺の町「凪浦（なぎうら）」です。リリースパッケージの examples/worlds/ ディレクトリには地形や雰囲気の異なる 7 種の完全なワールドパック（加えてエディタで改築したデモパック nagiura-edited 1 種）が同梱されており、12 業種の商業・公共店舗およびオープンカウンターでの自由注文（たとえばコンビニで温かいおでんを買うことができ、古書店や喫茶店の店主はそれぞれ独立した時間差の営業時間で出勤し、カウンターのコースターにメッセージを残せる仕組み）を備えています。

  • 海辺の町・凪浦（nagiura、なぎうら）：標準のサンプルワールドで、自宅、書店、カモメ珈琲、公園、ビーチなど 17 か所の地点と 18 本の道路を含みます（ほかに改築デモ版 nagiura-edited：18 地点・19 道路を同梱）。
  • 山あいの温泉街・湯川（onsawa）と嶺谷（mountain_town-demo）：翠沢の湯屋（hot_spring）、山の石段、渓谷の景色など各 15 か所の地点を含みます。
  • 水車の里・穂村（inobe）と沢郷（rural_farming-demo）：水車公園、田んぼのあぜ道、集落の工房など各 14–15 か所の地点を含みます。
  • 暮らしの街角・栞沢（wakaba）と日常街区・一（daily_neighborhood_v1）：前者には栞沢書店を含む 16 か所の生活エリアが、後者には営業時間や読書コーナー付きの軽量な 7 地点の生活圏が収録されています。各ワールドディレクトリには preview.html が同梱されており、ダブルクリックするだけでブラウザ上で道路網トポロジー図を確認できます。

ライト／ダーク両対応オフラインマップエディタ：間取り描画と店舗設定

リポジトリ内の components/world-editor/ には、ライトテーマとダークテーマの切り替えに対応して刷新された純ローカルのビジュアル空間エディタが内蔵されています（ローカルマシン 127.0.0.1 のみで待ち受けるため、インターネット接続不要でモデルのトークンも消費しません）。デスクトップ版の「街区 → エディタ」タブからそのまま開けるほか、ターミナルから手動で起動することもできます。

bash
cd ~/.local/share/nyairo/releases/v0.7.0/components/world-editor
python3 server.py --port 8766

続いてブラウザで http://127.0.0.1:8766 を開けば、ワールドの改築を始められます。

  1. 既存のワールドパックをエディタ形式へ変換する：python3 -m components.worldgen editor-export examples/worlds/nagiura を実行すると、パック内に editor-world.json が生成されます。
  2. ビジュアル編集と店舗注文メニューの設定：ブラウザからこのファイルをインポートすると、ライト／ダーク外観をいつでも切り替えながら、書店の名前や営業時間の変更、道路リンクの追加・削除、カスタム店舗のオープンカウンターメニュー（sale_spec）の設定を自由に行えます。さらに室内ビューに切り替えて壁を描いたり、ドアや窓を開けたり、収納機能や物性特性を持った机・ケトル・デスクランプなどを配置したりでき、「AI 視点プレビュー」をクリックすればパートナーが部屋の中でどの家具を視認できるかも確認できます。
  3. ワンクリック書き戻しと整合性チェック：画面上の「nyairo ワールドパックを書き出し」（または CLI の editor-import）を実行すると、変更したフィールドだけが差分更新され、既存の NPC や環境イベントはそのまま保持されます。同時に連結性チェックも自動で行われ、誤って唯一の出口を切断してしまったり、まだ NPC が出勤する店舗を削除してしまったりした場合は、平易なメッセージで具体的な競合箇所を指摘して破損データの書き出しを防ぎます。

テーマ選択不要の完全ランダム専用ワールドとシード値生成

v0.7.0 では、「海辺の坂道タウン（coastal_town）」「山あいの温泉町（mountain_town）」「郊外の住宅街（residential_town）」「田園の農村（rural_farming）」の 4 種類のテーマに沿った生成に加えて、デスクトップ版の「街区 → 新しい街を生成」からテーマ選択不要の完全ランダム専用ワールドをワンクリックで生成できるようになりました（procedural モード）。あらかじめスタイルを選ばなくても、ジェネレーターがシード値にもとづいて 6 種の地形（岬の坂道・運河と水路の路地・山麓の渓谷・鉄道の駅町・果樹園の台地・森の湖畔）から調和する景観を掛け合わせ、4 種の異なるトポロジーの連結道路網（放射状ハブ型・環状ルート・一本道プロムナード・分岐大通り）、8 業種の商業店舗、および複数部屋の自宅（寝室に加えてリビング、縁側、ミニキッチン、書斎コーナー、さらに温冷・乾湿の物性を持つ家具を自動組み合わせ）を構築し、「生成後すぐホットスイッチで反映」にも対応しています。

Linux / WSL のターミナルでお使いの場合も、components.worldgen に --theme procedural（または任意のテーマ）と数値シードを指定して、決定論的な専用ワールドをコマンド一発で生成できます。

bash
REL="$HOME/.local/share/nyairo/releases/v0.7.0"
cd "$REL"
# テーマ選択なしでシード値から完全ランダム専用ワールドを生成・検証し、プレビューマップを出力
"$REL/vendor/hermes/.venv/bin/python" -m components.worldgen generate \
  --theme procedural --seed 20261118 --out "$HOME/my-world"
"$REL/vendor/hermes/.venv/bin/python" -m components.worldgen validate "$HOME/my-world"
"$REL/vendor/hermes/.venv/bin/python" -m components.worldgen preview "$HOME/my-world" --out "$HOME/my-world/preview.html"

同じモードとシード値を使えば、生成される道路の所要時間、店舗メニュー、自宅の部屋構成はバイト単位まで完全に再現可能です（この処理で LLM は一切呼び出されません）。ワールドサービス起動時に環境変数 CHIYO_WORLD_PACKAGE="$HOME/my-world" を指定するだけで、そのワールドパックをマウントできます。

現在の実際の制限事項（未対応の仕様）

エディタやジェネレーターの挙動について誤解が生じないよう、現時点でまだ対応が完了していない実装上の境界線をあらかじめ共有します。

  • 初回起動時の選択なしゼロ設定ワールド生成は現在ブラッシュアップ中：デスクトップ版の「新しい街を生成」および CLI の --theme procedural ではテーマ選択不要の完全ランダム専用ワールドがすでに利用できますが、初回インストール直後にクライアントを開いた瞬間の質問ゼロ自動生成オンボーディングやコミュニティのワールドパック共有機能は 今後のロードマップ で開発を進めています。
  • 壁や床材は現時点では移動を遮りません：エディタで描いた壁面や床材は scene.json に保存され、ビジュアル表示と再編集時の復元に利用されます。下層のランタイムは現在「建物の入口 ↔ 室内の各エリア（寝室・リビングなど、移動所要 30 秒）」というノードグラフ上で経路探索を行っており、ピクセル単位の壁回避コリジョン判定はまだ実装されていません。
  • 店舗の営業時間で日をまたぐ表記には未対応：生成ワールドとエディタのカスタム店舗のどちらでもオープンカウンター注文（sale_spec）は動作しますが、店舗の営業時間に深夜 0 時をまたぐ時間帯（例：22:00–06:00）を指定することはまだできず、書き戻し時に非対応である旨が明示的に通知されます。
