今後のロードマップ：いま作っているものと、これから作るもの

現在のパブリックベータ版 v0.7.0 では、テンプレート不要の完全ランダム専用ワールドのワンクリック生成、12業種の店舗での自由注文、ロスレス引越しスーツケースをすでに実装しています。このページでは私たちが守り続けている「邪魔をしない境界線」と、今後のゼロ設定オンボーディング、四季のリズム、ワールド共有の計画を率直にお伝えします。

このプロジェクトを始めた原点

世の中には賢い質問応答チャット欄がすでに十分あります。足りないのは、ウィンドウを閉じたあとも向こう側の時間が流れ続け、長く腰を落ち着けて暮らせる「場所」でした。私たちが nyairo を作るうえで、ずっと大切にしている素朴な原則がいくつかあります：

  • 時間は本当に流れている：あなたが仕事で半日話しかけられなくても、向こう側の昼夜は普通に巡り、向こうなりのささやかな日常が進んでいます。
  • 空間には本当の距離がある：街の書店へ出かけるなら道中を数分かけて歩きます。途中で「いまどこ」と尋ねられれば、1秒で瞬間移動したりせず「まだ歩いている途中」と素直に答えます。
  • 世界は画一的であるべきではない：一人ひとり性格や好みが違うように、AI 個体が暮らす舞台もいつまでも同じ初期マップ1枚に固定されるべきではありません。
  • 記憶は自分の手元に置く：すべての会話と長期記憶はあなた自身の PC 内のローカルデータベースに保存され、特定の商用クラウドプラットフォームに縛られません。

達成済みマイルストーン · 完全ランダム専用ワールドとロスレス引越しスーツケース (v0.7.0)

現在の状況：テンプレート不要の完全ランダム専用ワールドとロスレススーツケースは v0.7.0 で実装済みです

パブリックベータ版 v0.7.0 では、海辺の「凪浦」、温泉の「湯川」、田園の「穂村」、街角の「栞沢」など7種の内蔵ワールドと4種のテーマスタイルを残したうえで、新たにテンプレート不要の完全ランダム専用ワールドのワンクリック生成（6種の地形ミックス、4種の異なる道路網構造、8業種の商業店舗、複数部屋の住宅）に対応しました。さらにダーク／ライト両対応へ刷新されたオフライン視覚マップエディタと、ワールドスライスや移行ロス一覧ごとまとめて持ち運べる .nyairo-suitcase.zip ロスレス引越しスーツケースも備えています。

「世界にひとつだけの日常の街に暮らす」ことを軸に、v0.7.0 では以下の機能がすでに動作しています：

  • テンプレート不要のランダム創世とエディタでの微調整：ランダムシードだけで多彩な地形の微気候、つながりのある道路トポロジー、オープンカウンター店舗、複数部屋の住まいを組み合わせられます。暮らし始めたあとでも、オフラインエディタで壁や扉を描き足したり、家具を増やしたり、小店のメニューを調整したりできます。
  • 12業種の街の店舗、バッグのネスト収納、温度・湿度の物性：コンビニの温かいおでんなどのオープンカウンター自由注文、古書店や純喫茶の店主による時差営業とカウンターのコースターメモを実装。携帯バッグは最大3階層のネスト収納に対応し、机の温かいお茶は自然に冷め、窓辺の紙メモは雨の湿気でわずかににじみます。
  • ロスレス引越しと基盤 LLM の自由な載せ替え：二層メモリーランタンが原文記録を改ざんゼロで保護します。.nyairo-suitcase.zip は API キーを自動除外しながら記憶帳簿・エッセイ作品・カスタムワールドスライス・透明性の高い移行ロス一覧をまるごと持ち運べるため、PC を買い替えても次世代の LLM へ切り替えてもこれまでの日々が失われません。

意図的に守り続ける境界線：勝手な通知連発なし・原文改ざんゼロ

実装漏れではなく、毎日のそばに居心地よく長くいられるようにあえて作らないと決めていることがあります：

  • やり取りがないときの勝手なポップアップ通知はしない：ツール扱いを排した日常の自律的な拒否境界を備え、睡眠中・外出中・集中作業中は急がない用件をスマホ返信トレイに入れて実際のスケジュール通りに数時間おきに非同期返信します（本当に急ぎのときは扉を叩いて呼び出せます）。ただし、あなたから話しかけておらず事前の約束もない状態で、バックグラウンドから勝手に WeChat や Telegram へポップアップ通知を送り続けて存在感をアピールするようなことは一切しません。
  • 自律生活で記録された出来事本文の直接改ざんは許さない：会話の中であなたが言い間違えた事実は /chiyo_memory correct で訂正できます（二層メモリーランタンは下層の原文をそのまま保持します）。一方で、向こうがバックグラウンドで散歩したり読書したりして積み上げた出来事の本文を直接書き換えることはできず、今後思い出してほしくない場合は /chiyo_memory delete で呼び出しを停止できます。

次のステップ · ゼロ設定の出会いガイド、四季のリズムとワールド共有

空間生成とロスレス引越しの基盤が整った今、今後の反復開発ではより滑らかな初対面の体験と長期的な暮らしの息づかいに注力していきます：

  • 初回起動時のゼロ設定オンボーディングガイド：クライアントを初めて開いた際の環境セルフチェック、モデル疎通（DeepSeek / ローカル Ollama のワンクリック検証）、そして完全ランダム専用ワールドの扉を開ける瞬間までをひと続きの没入型ガイドとしてまとめ、まったくの初心者でも設定画面を探し回らずに自然と暮らしを始められるようにします。
  • より深い季節の移ろいと近隣の生活リズム：街の光や風物、お店の季節限定メニュー、店主との日常的な雑談が春夏秋冬に合わせて自然に移り変わり、数か月から1年単位の時間の奥行きが積み重なるようにします。
  • 軽量なコミュニティ向けワールドパックとベース設定の共有：ワールドパックとニュートラルな設定テンプレートの検証・プレビュー規約を整備し、オフラインマップエディタで作った個性豊かな街や街角の本屋、メニューレシピを手軽に共有してワンクリックで試し住みできるようにします。

これまでの歩み · ローカル記憶基盤 (v0.1)

プロジェクト最初のバージョン（v0.1.0-rc4〜rc9）では、まず最も土台となる基盤を固めました：

  • 長期記憶をローカル SQLite へ保存し、いつでも閲覧・訂正・呼び出し停止ができるようにしました。
  • プログラムディレクトリと個人データを分離し、再起動しても途切れず、コマンドアップデートでもデータが消えない仕組みを整えました。

これまでの歩み · 空間の原型と実時間徒歩 (v0.2)

v0.2 の段階では、歩いて回れる部屋と街並みを初めて用意しました：

  • オフラインで動作する単体マップエディタと複数のサンプルテンプレートを同梱しました。
  • 道路網の距離に応じて時間を計測する移動ツールを接続し、スマホの WeChat 個人チャットともつなぎました。

これまでの歩み · 連続する日常とデスクトップ版 (v0.3 – v0.7.0)

v0.3.0 から現在の v0.7.0 にかけて、空間での単発アクションを一貫した日々の暮らしへと育ててきました：

  • 複数区間の連続経路探索、途中一時停止からの歩行再開、複数タスクの一時中断・復帰、日をまたぐ街の見聞を実現しました。
  • テンプレート不要の完全ランダム専用ワールド、12業種の店舗での自由注文、バッグのネスト収納と温度・湿度の物性、自律的な拒否境界と非同期返信を加えました。
  • 管理者権限不要でワンクリック導入できる Windows ネイティブデスクトップクライアントと、ロスレス引越しスーツケース .nyairo-suitcase.zip を実装しました。これからの計画についても、引き続き一つ実装し終えてから誠実に完了マークを付けていきます。
