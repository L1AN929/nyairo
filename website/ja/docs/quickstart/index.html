はじめての方へ：ここからスタート

お使いの PC に合わせた一番手軽な導入方法を選べます。Windows ならデスクトップ版をインストールするだけで始められ、初心者の方でも数百円の DeepSeek キーまたは無料のローカル Ollama を繋げばすぐに対話を開始できます。

まず環境に合った導入方法を選ぶ

始める前に必要なものは、インターネットにつながる PC 1台と LLM API（数百円チャージの DeepSeek API キー、または PC 上の無料 Ollama のどちらでも可）だけです。お使いの OS に合わせてお選びください。

  • Windows 10 / 11 をお使いの場合（推奨）：約 5.8 MB の Windows デスクトップ版インストーラー をダウンロードしてダブルクリックするだけで、WSL 2 を自動検出し、バックグラウンド環境の構築まで案内してくれます。ターミナルコマンドを覚える必要はありません。詳しい手順は Windows へのインストール、画面の使い方は デスクトップクライアント利用ガイド をご覧ください。
  • Linux をお使いの場合、またはターミナル操作に慣れている場合：すぐ下のワンライナー導入手順へお進みください。
  • 普段 Claude Code や Codex などのコーディングアシスタントを使っている場合：AI アシスタントに自動導入を任せる にある標準プロンプトをそのままコピーして渡すだけで導入を代行してもらえます。

Windows 初回起動時に「Windows によって PC が保護されました」と出た場合の2ステップ図解

nyairo は個人・独立系のオープンソースプロジェクトであり、高額な商用 EV コード署名証明書をまだ取得していないため、初回に nyairo-0.7.0-setup.exe をダブルクリックした際、Windows SmartScreen の通常の確認画面が表示されることがあります。以下の2ステップでそのまま開けます（管理者権限は不要です）：

  1. まず画面の案内文の下にある「詳細情報」をクリックしてインストーラーの詳細を展開します。
  2. 念のためインストーラーの SHA256 が公式サイト公開値の 174e459727af67c5d97204abd69dd7ce0741ed056a084fc64ba78a187bc14dd8 と一致することを確認し、右下に現れる「実行」をクリックするとセットアップウィザードへ進みます。

Linux / WSL のワンライナー導入

Linux ターミナル（Windows でターミナル版を使う場合は先に Ubuntu ウィンドウ）を開き、次のコマンドをコピーして Enter を押してください：

bash
curl -fsSL https://nyairo.com/install.sh | bash

実行前にハッシュ検証を行いたい場合は、公式アーカイブとチェックサムファイルを段階的にダウンロードできます：

bash
curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.7.0/nyairo-v0.7.0.zip
curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.7.0/nyairo-v0.7.0.zip.sha256
sha256sum -c nyairo-v0.7.0.zip.sha256
python3 -m zipfile -e nyairo-v0.7.0.zip "$HOME/apps/nyairo-v0.7.0"
cd "$HOME/apps/nyairo-v0.7.0" && bash scripts/bootstrap.sh

事前に Python や Git を入れておく必要はありません。スクリプトが公式の v0.7.0 リリースパッケージを自動取得・検証し、Python 3.13 の実行環境を整えたうえで、~/.nyairo 配下に個人用データディレクトリを作成します。

ターミナルに [5/5] 程序安装完成（インストール完了）と表示されると、自動的にモデル設定ウィザードへ進みます：

  1. 上下の矢印キーで利用するモデルプロバイダーを選択します。
  2. ご自身の API キーを貼り付けます（サードパーティの互換エンドポイントを使う場合は、あわせて Base URL も入力してください）。
  3. Enter キーで保存するとそのまま対話画面に入ります。「こんにちは」などと送ってみて、返事が届けば導入完了です。
curl が見つからないと表示された場合

ごく一部の初期状態の Ubuntu イメージには curl が入っていないことがあります。その場合は先に sudo apt update && sudo apt install -y curl を実行してから、上のインストールコマンドを再度お試しください。

初心者向けモデル設定：数百円の DeepSeek キーまたは無料 Ollama

これまで API キーを発行したことがなくてもご安心ください。nyairo の決定論的基盤は高価なモデルを必要としないため、次の2つの手軽な方法のどちらでもすぐに動かせます。

  • 方法 A（おまかせ推奨 · GPU 不要）：数百円（5〜10元）で DeepSeek キーを取得する：ブラウザで platform.deepseek.com を開いて登録・ログインし、チャージページ（Top up）から 5〜10 元（数百円程度、日常の会話は1回わずか数分の1円ほどなので長期間使えます）をチャージします。左メニューの「API keys → Create new API key（作成）」から生成した sk-... キーをコピーし、デスクトップクライアントの「設定 → モデル」（モデルは deepseek-chat を選択）に貼り付けて「保存」と「接続テスト」を押せば完了です。
  • 方法 B（完全無料 · 外部通信ゼロ）：ローカルの Ollama を直接接続する：ollama.com から Ollama をインストールし、軽量モデルを取得します（例：ollama pull qwen2.5:7b）。バックグラウンドで http://127.0.0.1:11434 が待ち受けている状態で、デスクトップ版の「設定 → モデル」からローカル Ollama / OpenAI 互換エンドポイントを選び、URL に http://127.0.0.1:11434/v1、API キーに ollama と入力すれば、会話データが一切 PC の外へ出ない環境が整います（詳しい手順は 日常の起動・人物設定とモデル をご覧ください）。

インストール後のチャット方法

  • デスクトップ版をご利用の場合：デスクトップまたは画面右下タスクトレイの nyairo アイコンをクリックするとウィンドウが開きます。サイドバーから「概要」「対話」「街区」「記憶」「設定」を切り替えられます。
  • ターミナルをご利用の場合：普段はターミナルを開いて nyairo と入力して Enter を押すだけで前回の続きから話せます。/chiyo_status を打つと記憶（READY）や生活状態（IDLE）がオンラインか確認でき、モデルを変更したいときはいつでも nyairo setup model を実行できます。
  • スマホの WeChat と連携する：外出先でもスマートフォンから話しかけたい場合は、WeChat 連携手順 に沿って QR コードをスキャンするだけで紐づけできます。

パートナーに名前を付け、性格を設定する

初期状態の人物設定はまっさらな白紙ベースです。名前を付けたり、話し方やふたりの間の呼び方を決めたりしたい場合は、個人用ディレクトリにある SOUL.md をエディタで開いて編集します：

bash
nano "$HOME/.nyairo/SOUL.md"

普段使っている自然な日本語で、パートナーの名前や、落ち着いた性格か明るめの性格か、あなたのことをどう呼ぶかなどをそのまま書き込んでください。書き終えたら Ctrl + O を押して Enter で保存し、Ctrl + X で閉じると、次回の対話から新しい設定が反映されます。
