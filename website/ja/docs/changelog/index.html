バージョンについて

現在の最新リリースは v0.7.0（GitHub prerelease 公開テスト版であり、正式安定版ではありません）で、ネイティブ Windows デスクトップインストーラー（nyairo-0.7.0-setup.exe）も提供しています。これまでに公開した v0.6.0、v0.5.1、v0.4.0、v0.3.0、v0.2.0-rc3 などの過去タグやアーカイブもそのまま保持されています。アップグレード前には、念のためご自身の ~/.nyairo ディレクトリをバックアップしておくことをおすすめします。

v0.7.0 · 完全ランダムワールド・オープン店舗・対等な境界線・ロスレス引越し（GitHub prerelease）

パブリックベータ版 · テンプレート不要のランダム生成、12業種の自由注文、自律的なお断りと非同期返信、バッグ・物性エンジン、端末間の丸ごと引越し

このバージョンでは、空間の自由度、日常の息づかいを感じる距離感、物理的な状態変化、そしてロスレスな引越し体験を一つの流れとして完成させました。

  • テンプレート不要の完全ランダム専用ワールドとダーク／ライト両対応オフラインエディタ：7つの内蔵ワールドと4種類のテーマスタイルに加え、テンプレート選択なしで世界にひとつの専用ワールドをワンクリック生成できるようになりました（6種の地形ミックス、4種の非均一道路ネットワーク、8業種の商業店舗と複数部屋の自宅）。オフライン視覚ワールドエディタも刷新され、ワークスペースのダーク／ライト表示切替に対応しています。
  • 12業種の店舗オープン注文と店主の時間差日常：12業種の街区店舗やオープンカウンターでの自由注文（コンビニへ歩いて温かいおでんを買うなど）に対応しました。古書店や喫茶店の店主はそれぞれの時間差リズムで出勤・営業しており、カウンターにコースター伝言を残すこともできます。
  • 便利屋扱いされない自律的な境界線と実日程に沿った非同期返信：引き受けたくない依頼は接客のような定型謝罪テンプレートを使わずきっぱり断り、あとまで引きずることもありません。実際の予定に沿って数時間後に非同期で返信したり、睡眠・外出・集中時間中の急がない連絡をスマホ返信トレイに保留し、急用のときはノックして呼び出したりできます。
  • 持ち物バッグの3階層ネスト収納と温度・湿度の物性：持ち物バッグや収納ボックスは最大3階層のネスト収納と厳密な容器可視性ルールに対応しました。アイテムにはリアルな温度・湿度の状態変化があり、机のそばの温かいお茶は自然に冷め、窓辺の紙片は雨に当たるとわずかに湿って文字が滲みます。
  • 二層メモリーランタンとロスレス引越しスーツケース：二層メモリーランタンにより会話原文の改ざんを厳密に防ぎます。ロスレス引越しスーツケース .nyairo-suitcase.zip を使えば、カスタム／ランダムワールドの断面データと移行差分レポートごと丸ごと持ち出せます（API キーとローカルパスは自動で除外され、インポート前に2段階の安全チェックを行います）。
  • 1日あたりのモデル使用量上限とデスクトップ版の堅牢化：初期設定で1日 50,000 Token の予算上限とウェイクアップチケットの照合による使いすぎ防止を導入しました。Windows デスクトップ版の導入ガイドとゲートウェイの排他保護もあわせて強化しています。

v0.6.0 · 日常の行動レシート・未来の質問と共読体験（GitHub prerelease）

パブリックベータ版 · 日常のやり取りとデスクトップ版体験のアップデート

このバージョンでは、日々の会話、街の散歩、ふたりでの共読、そしてデスクトップクライアントの細かな使い心地を重点的に磨き上げました。

  • 会話中の生活ステータスと行動レシート：チャット画面の上部に、パートナーが今いる部屋や通り、姿勢、手元の作業状況がリアルタイムで表示されます。会話の中で散歩に出たりエッセイを書いたりしおりを挟んだりする実際の行動が発生すると、吹き出しの下にクリックできるカプセルボタンが現れ、対応するマップや原稿へワンクリックで移動できます。
  • 未来の質問と習慣トピック管理：デスクトップ版の「記憶 → 暮らしと実践」から、パートナーがあとで聞きたがっている質問を手動でメモしたり、その場で答えたり取り消したりできるようになりました。よく話題にする約束事も習慣トピックとして蓄積し、「概要」ページからワンクリックで会話に呼び出せます。
  • 共読サンプルブックと初回ガイド：共読本棚に『凪浦海風手記（共読サンプル）』をワンクリックで追加して、ページめくり・しおり・ページごとの余白メモをすぐに試せるようになりました。新しいワールドでは、起床・水分補給・エッセイ執筆・書店巡りの4ステップの軽やかな案内が用意されています。
  • モデル API のワンクリック接続テスト：デスクトップ版の「設定」ページに LLM API の疎通テストボタンを追加しました。応答時間やエラー原因がその場で返ってくるため、手探りで原因を探す手間が省けます。

v0.5.1 · 身体リズム・朝晩の街並み・デスクトップ版（GitHub prerelease）

パブリックベータ版 · 分割テストおよびリリースマニフェスト検証完了 · Windows デスクトップ版同時公開

このバージョンでは、日々の生活リズム、街の細部、アルバムや原稿、そしてデスクトップクライアントに関する開発成果を、そのままインストールして試せるテスト版としてまとめました。

  • Windows ネイティブデスクトップクライアント：管理者権限不要の約 5 MB インストーラー（インストール手順）を新たに追加しました。システムトレイに常駐し、初回起動時に WSL 2 を自動検出して環境構築を案内します。概要、ストリーミング引用対話、街と室内の見取り図、原稿差分比較、WeChat QR スキャンパネルを内蔵しています。
  • 生活と補給のリズム：眠気・休息、水分補給、軽食の時間リズムを追加し、それぞれの動作が実際の所要時間に沿って進行するようになりました（現時点では軽量なリズム管理であり、本格的な空腹度・栄養数値システムではありません）。
  • 朝晩で変わる街の表情と読める風景：同じ通りでも朝と夕方・夜で異なる雰囲気を見せるようになり、道端の設備や読書コーナーに立ち止まって詳しい内容を読むことができます。
  • アルバム・日記・原稿の書き継ぎ：カメラでの写真撮影、アルバムの閲覧、ふたりでの共読メモに加え、書きかけ原稿の一時保留・再開や過去バージョンとの差分比較を揃えました。
  • ビルド整理と機密情報マスキング：インストーラーのバージョン番号と記憶モジュールの明示的な設定を統一し、公開ソースコード内の内部テスト用アドレスを完全に除去しました。
v0.5.1 公開当時の検証範囲メモ

機能別の分割テスト、9項目のマスキング済みオフライン検査、MANIFEST.json と ZIP ハッシュの照合、およびデスクトップ版の実機結合テストを完了しています。このリリース時点では、過去4万件以上のホスト側全量回帰テストの再実行や、実 LLM を接続した24時間連続稼働テストは未実施でした（なお、当時未統合だった完全ランダムワールドと引越しスーツケースはその後の v0.7.0 で実装済みです）。

v0.4.0 · 複数区間の移動とタスクの一時保留（GitHub prerelease）

パブリックベータ版 · ワールド・身体基盤の専用テスト 263 項目に合格

0.3 で実現した単発外出の行動ループをベースに、0.4 では「少し遠い場所へ複数区間に分けて歩くこと」と「複数の用事を切り替えながら進めること」を解決しました。

  • 複数区間の連続移動：離れた場所へ向かう場合、自動で複数の区間（例：寝室 → リビング → 通り → 書店）に分割して順番に進みます。各区間ごとに進捗が保存されるため、途中で足を止めても位置が飛びません。
  • 複数タスクの保留と単一集中：今すぐ終わらない用事があれば、待機条件をメモして一時保留し、別の用事を先に済ませられます。条件が満たされた時点で続きを再開でき、表で同時に走る行動は常にひとつに保たれます。
  • 日をまたぐ天気と街の出来事：天候の移り変わりやご近所のちょっとした出来事が数日間にわたって段階的に変化し、期間を過ぎると自然に区切りがついて無限ループしなくなりました。
  • より明確なステータス応答：異なる行動間でアクション番号がまれに混線する不具合を修正しました。また、「操作が拒否された」場合と「結果が一時的に不明」な場合を明確に区別し、同じエラーとして混同しないようにしました。
  • 原稿のバージョン比較：管理下の原稿に過去バージョンの一覧と追加・削除の差分ビューを追加し、書き継ぐ際には前バージョンの要約を自動で参照するようにしました。

v0.3.0 · 外出・買い物と途切れない行動ループ（GitHub prerelease）

パブリックベータ版 · 8グループ 51項目のコア機構チェックに合格

このバージョンでは、外出から道中の待機、急な予定変更、店での買い物、そして帰宅して元の作業に戻るまでを、一時停止や再開が可能なひとつの連続したプロセスとして結びつけました。

  • 実際の道路グラフに基づく経路探索：現在のマップから場所や部屋の扉・出入口を直接解決し、名称が曖昧な場合や道がつながっていない場合はその旨を正直に伝えるようにし、固定値による瞬間移動を廃止しました。
  • 途中一時停止でもやり直しなし：一時停止の指示はこれから出発する次の区間だけを止め、すでに歩き始めている区間はきちんと歩ききってから停止し、再開時はその地点から歩き続けます。
  • 通信の揺らぎによる二重実行を防止：アクション送信後に応答が返らなかった場合、まず台帳の結果を照合することで、不用意な再送で同じ行動を2回実行してしまうのを防ぎます。
  • 1日あたりのモデル呼び出し予算：日単位および1回の実行ウィンドウ単位でリクエスト上限を設定でき、一時停止中に裏側でこっそり枠を消費することはありません。
  • 店舗での買い物と体験の記録：店で購入した飲み物や読み物は実際に消費・記録され、その後の会話や選択にも直前の出来事として反映されます。数日先までの店舗営業時間スケジュール照会にも対応しました。

v0.2.0-rc3 · チャットからの移動指示と移動中の経過認識

公開日：2026年10月14日

  • ひと言で外へ出かける：移動ツール world_move を追加しました。ターミナル、WeChat、Telegram からコンビニや公園へ行くようそのまま話しかけるだけで、隣接していない場所へも通りを経由して自動で向かいます。
  • リアルな徒歩所要時間：各区間は距離に応じて5〜13分程度の徒歩時間がかかり、移動の途中でメッセージを送って尋ねると、到着まであと何分くらいかを正確に答えてくれます。
  • 権限許可とテスト整備：記憶のセキュリティポリシーが移動ツールを誤ってブロックしてしまう不具合を修正し、16項目の専用テストとファイルマニフェスト検証を追加しました。

v0.2.0-rc2 · インストール・アップグレード用メタデータの修正

rc1 アーカイブ内の更新登録バージョン番号が古いままになっていた問題を修正し、バージョン不一致を防ぐ自動パッケージ検証スクリプトを追加するとともに、Telegram 連携ガイドのコマンド誤記を訂正しました。

v0.2.0-rc1 · 自律的な日常とマップエディタ

公開日：2026年10月13日

  • バックグラウンド自律リズム（初期状態オフ）：有効にすると、話しかけられていない間も自分のリズムで目を覚まし、周囲を見回したり散歩したり、書きかけのエッセイを書き継いだりします。
  • 確認できた結果だけを記録：LLM が「保存したと口では言いながら実際には書き込めていない」状態を防ぐため、下層サービスで書き込み成功が確認できた場合のみ台帳へ記録し、曖昧な状態は正直に「不確定」として扱います。
  • オフラインマップエディタ標準同梱：視覚的な空間エディタと複数の街テンプレートを同梱しており、ブラウザ上で壁を描いたり扉を取り付けたり家具を配置したりできます。

v0.1.0-rc9 · Agent 支援インストールとコミュニティ窓口

公開日：2026年10月10日

  • AI Agent 支援インストール仕様：AGENT_INSTALL.zh-CN.md を公開しました。標準プロンプトを Claude Code や Codex などのツールへコピーするだけで、環境の事前確認、インスタンス分離、SHA256 検証付きインストールまで自動で進められます。
  • コミュニティ窓口：公式 QQ 交流グループ（1126943805）および Telegram チャンネル（@nyairoai）を開設し、不具合報告や設定のノウハウ交換をしやすくしました。
  • ドキュメントサイトの体裁調整：公式サイトのファーストビューとドキュメントの閲覧レイアウトを改善しました。

v0.1.0-rc6 · 1コマンドでの更新とロールバック

公開日：2026年10月6日

  • 丸ごとスムーズなアップグレード：nyairo update を追加しました。~/.local/share/nyairo 配下のプログラム本体のみを置き換え、~/.nyairo 内の会話履歴、記憶、API キー、SOUL.md はそのまま保持されます。
  • ワンコマンドのロールバックと中断復旧：更新後に互換性の問題が出た場合は、nyairo update --rollback で前のバージョンへ戻せます（その間の新しい会話も失われません）。通信切断で中断した場合は nyairo update --recover で修復できます。

v0.1.0-rc5 · カスタム人物設定とプライバシー強化

公開日：2026年10月4日

  • 人物テンプレートの分離：新規インスタンスでは初期状態としてクリーンでニュートラルな SOUL.md テンプレートを採用し、名前・呼び方・性格を自由に設定しやすくしました。
  • 短い会話の文脈漏れ修正とツール制限：短いやり取りで文脈がまれに抜け落ちる不具合を修正しました。また、記憶モード有効時は任意のファイル読み取りツールを初期状態で制限し、モデルが「呼び出し停止」設定を迂回して過去ログを覗き見るのを防いでいます。

v0.1.0-rc4 · 初のパブリックプレビュー版

公開日：2026年10月2日

ローカル SQLite 長期記憶、再起動をまたいで保持される生活状態、そして初期の位置・姿勢認識インターフェースなど、nyairo の基本骨格を構築しました。
