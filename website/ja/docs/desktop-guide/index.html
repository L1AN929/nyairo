デスクトップクライアント利用ガイド

Windows デスクトップ版の 5 つのメインタブ、12 業種の店舗注文とバッグの物性、非同期返信と拒否の境界線、SOUL.md の保護、そしてロスレス引越しスーツケースまでをまとめて解説します。

概要と対話：会話の続き・スマホ返信トレイ・急ぎのノック

デスクトップ版では煩雑なバックグラウンド動作パラメータを折りたたみ欄に整理しており、普段使うのは主に左側の先頭 2 つのタブです。

  • 概要：上部のすっきりしたステータス行に、パートナーがオンラインかどうか、稼働時間、記憶している件数が表示されます。左ペインには直前のやり取りとクイック入力欄が並んでおり、画面を切り替えずにそのまま会話を続けられます。右ペインには最近記憶した元の発言がいくつか表示されます（重複を避けるため、左ペインに表示されたばかりの発言は自動で除外されます）。下部の「動作詳細」は初期状態で折りたたまれており、開いたときだけ各モジュールの状態やバックグラウンドイベントを確認できます。
  • 対話と心地よい距離感：1 文字ずつ滑らかに表示されるストリーミング返信、ホバーでの単一メッセージコピー、特定の文を選択しての引用フォローアップ、通信切断時のワンクリック再試行、現在のセッションのローカル Markdown ファイル書き出しに対応しています。日常会話には道具扱いをしない自律的な拒否の境界線を備えており、気が進まない頼みごとは定型謝罪テンプレートを並べることなくきっぱり断り、根に持つこともありません。就寝中・外出中・集中している時間帯に届いた急ぎでない連絡は、まずスマホ返信トレイに入り、実際のスケジュールに沿って数時間後に非同期で返事が届きます。本当に急ぎの用件がある場合は、明示的にノックして呼び出すことも可能です。

街区・12 業種の店舗・バッグの物性と 4 つの記憶タブ

  • 街区と持ち物の物性：現在のワールド（テンプレート選択不要の完全ランダム専用ワールドのワンクリック生成、7 種の内蔵ワールド、4 種のテーマスタイルに対応）と部屋の間取りをひと目で確認できます。場所をクリックして歩いて向かわせたり照明をオン・オフしたりできるほか、最大 3 階層のネスト収納に対応した持ち物バッグや温度・湿度の物性変化（机の温かいお茶が時間とともに冷めたり、窓辺のメモが雨でわずかに湿ってインクがにじんだりする状態）を確認したり、ライト／ダーク両対応のオフラインマップエディタを開いたりできます。
  • 店舗（12 業種のショップで自由注文が可能）：12 業種の街角ショップとオープンカウンターでの自由注文（例：コンビニで温かいおでんを買うなど）に対応しています。古書店や喫茶店の店主はそれぞれ独立した時間差の営業時間で店に立ち、カウンターのコースターにメッセージを残すこともできます。なお、店舗は現実の空間ルールに従うため、実際に営業中の店舗まで歩いて中に入ったときだけ買い物や注文が可能です。自宅にいる状態で開くと「現在は店内にいません」と正直に表示されます。
  • 記憶（二層メモリーランタンと 4 つのサブタブ）：
    • 常駐記憶：下層では二層メモリーランタンの仕組みにより会話の原本を一切改ざんせず厳格に保護しています。右上の検索ボックスから記憶済み項目をキーワードでリアルタイムに絞り込め、手動での訂正や呼び出し停止にも対応しています。
    • エッセイと創作：パートナーが書いたエッセイや管理対象の原稿をまとめて閲覧し、過去の版どうしの追加・削除差分を比較できます。
    • アルバムと共読：残されたポストカードアルバムを見返したり、テキストの本や記事を読み込んで一緒に読み進めたりできます（詳しくは次章「共読・原稿・アルバムと生活リズム」をご覧ください）。
    • 共にある時間と予定：最近の共同活動の記録、未来へ向けた問いかけ、共有している話題や ToDo の予定を確認できます。

自由な呼び名・代名詞と SOUL.md 保護

左下の「設定 → 人物設定と好み」から、パートナーの名前や三人称の呼び方をいつでも変更できます。

  • 代名詞を完全自由に入力可能：定番のクイックボタン（相手・彼・それ など）に加えて、入力欄には 8 文字以内の任意の呼び方を自由に入力できます。クライアント全体の文言も設定した名前に連動して動的に変わるため、固定の性別代名詞が押し付けられることはありません。
  • 手動で編集した SOUL.md を意図せず上書きしない保護機能：基本の呼び名を保存する際、クライアントは内容のフィンガープリントを記録します。あとからご自身で詳しいカスタム SOUL.md を書き上げた場合（設定画面上で編集しても、ファイルを直接編集しても同様です）、デスクトップ版がフィンガープリントの変化を検知して自動的に保護を有効化します。そのため、その後に画面上の表示名を変更しても SOUL.md 本体の本文が乱暴に書き換わり、せっかくの内容が失われることはありません。最初からやり直したいときは「デフォルトテンプレートに戻す」をクリックしてください。

実用上のポイント：「新しい対話」と記憶の呼び出しウィンドウ

デスクトップ版で会話する際、あらかじめ知っておくと安心な内部仕様があります。

  • 同じスレッドでそのまま会話を続ける（推奨）：「新しい対話」を押さない限り、丸一日空いたり PC を再起動して戻ってきたりしても、ローカルに永続保存された会話履歴をもとに以前の細かなやり取りを正確に覚えています。
  • 「新しい対話」を押したあと：新しいセッションを開いてから 15 分以内であれば、直前の会話記録ウィンドウから文脈を自動で引き継ぎます。一方で、最後の発言から 15 分以上経ってから新しいセッションを開いた場合は、雑談の断片を新しい話題に誤って混ぜないよう、まだアーカイブされていない長い会話の細部は一時的に自動注入されないことがあります。そのため、普段はチャットアプリのようにそのまま続けて話し、本当に話題をリセットして一から始めたいときだけ「新しい対話」を使うのが最もスムーズです。

タスクトレイ常駐・ショートカット・ロスレス引越しと匿名化診断パック

  • タスクトレイ常駐と二重起動防止：ウィンドウ右上の閉じるボタンを押すと、初期設定では右下のシステムトレイに格納されます。トレイアイコンを右クリックすれば、いつでも「ゲートウェイを再起動」、ログフォルダを開く（%LOCALAPPDATA%\nyairo\desktop.log）、または完全終了を行えます。クライアントには単一インスタンスロックが内蔵されており、誤って 2 つのウィンドウを開いて同じバックグラウンドゲートウェイを取り合うのを防ぎます。
  • グローバルクイックコマンドパネル：ウィンドウ内で Ctrl + K を押す（または上部バーの虫眼鏡アイコンをクリックする）と、クイックコマンドや街区の場所検索をいつでも呼び出せます。
  • ロスレス引越しスーツケースによるバックアップと復元：「設定 → 環境と診断」（または概要ページの「お引っ越しスーツケース」カード）から、API キーやローカル環境固有パスを自動除外した .nyairo-suitcase.zip をワンクリックで書き出せます。二層メモリーランタンの帳簿、カスタム／ランダム生成ワールドのスナップショット、移行時のチェックリスト一式をまとめて持ち出せるほか、新しい PC へインポートする前には 2 段階の安全プリチェックが自動実行されます。
  • 機密マスク済み診断パックのワンクリック書き出し：不可解な不具合で開発者に調査を依頼したいとき、ご自身で WSL 内から設定ファイルを探し回る必要はありません。「設定 → 環境と診断」を開いて診断パックの書き出しをクリックすると、ローカルで diagnose-タイムスタンプ.zip（モジュール状態サマリー、ログ末尾 300 行、設定コピーを同梱）を生成します。その際、すべての api_key・token・secret・password 項目は自動的に <redacted> へマスク置換され、個人のチャットデータベースや SOUL.md の本文も含まれないため、コミュニティやサポートへ安心して共有できます。
