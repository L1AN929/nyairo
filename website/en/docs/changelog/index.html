Release Note

The latest release is v0.7.0 (a public GitHub prerelease, not yet a final stable release), alongside a native Windows desktop installer (nyairo-0.7.0-setup.exe). Earlier tags and archives—including v0.6.0, v0.5.1, v0.4.0, v0.3.0, and v0.2.0-rc3—remain preserved as-is. We recommend backing up your ~/.nyairo directory before upgrading.

v0.7.0 · Fully Randomized Worlds, Open Shops, Boundaries & Lossless Suitcase (GitHub prerelease)

Public prerelease · Zero-setup procedural worlds, 12 shop types with free-form ordering, autonomous refusal & async replies, nested bag item states & cross-device migration

This release closes the full loop across spatial freedom, lifelike conversational pacing, physical item states, and lossless cross-machine migration:

  • Zero-Setup Randomized Personal Worlds & Light/Dark Offline Editor: Alongside 7 built-in worlds and 4 theme styles, adds one-click generation of fully randomized personal worlds (6 terrain mixes, 4 heterogeneous street networks, 8 commercial shop categories, and multi-room residences), paired with an updated offline visual world editor supporting light and dark workspace themes.
  • 12 Neighborhood Shop Types & Staggered Owner Routines: Opens 12 neighborhood shop categories and free-form open-counter ordering (for instance, walking to a convenience store to buy hot oden). Used bookstore and coffee shop owners keep independent staggered work schedules and support leaving coaster notes at the counter.
  • Non-Servile Autonomous Refusal Boundaries & Real-Schedule Async Replies: When asked for a favor they would rather not do, they decline plainly without canned customer-service apologies or holding grudges. Supports asynchronous replies spaced hours apart on a real schedule, routing non-urgent messages to a phone reply inbox while sleeping, out, or focused—while still letting you knock on their door for real emergencies.
  • 3-Level Nested Carry Bags & Thermal/Moisture Item States: Carry bags and storage boxes support up to 3 nesting levels with strict container-scope isolation. Items carry realistic thermal and moisture states—hot tea beside a desk cools down naturally, and paper notes by a window turn slightly damp with blurred ink in the rain.
  • Dual-Layer Memory Lamp & Lossless Moving Suitcase: The dual-layer memory lamp strictly prevents tampering with raw conversation transcripts. The lossless moving suitcase (.nyairo-suitcase.zip) packs everything—including custom or randomized world slices plus a migration loss manifest (automatically stripping API keys and local paths, with a two-step pre-import safety check).
  • Daily Token Cap & Desktop Hardening: Adds a default daily 50,000-token budget cap with wake-ticket reconciliation to prevent overspending, alongside upgraded Windows desktop onboarding and gateway mutual-exclusion protection.

v0.6.0 · Daily Interaction Receipts, Future Questions & Shared Reading (GitHub prerelease)

Public prerelease · Everyday interaction and desktop client polish

This release focuses on refining everyday chat, neighborhood walks, two-person shared reading, and desktop client ergonomics:

  • Live Presence & Action Receipts in Chat: The top of the chat window displays their current room or street, body posture, and active progress in real time. Whenever conversation triggers a real action—like heading out for a walk, writing an essay, or adding a bookmark—a clickable jump pill appears below the message bubble to jump straight to the matching map location or manuscript.
  • Future Questions & Recurring Conversation Starters: Under "Memory → Coexistence & Practice" in the desktop app, you can jot down questions they want to ask you later, answer or cross them off anytime, and distill recurring shared understandings into habitual starters for one-click insertion from "Overview".
  • Shared Reading Demo Book & Starter Walkthrough: The shared bookshelf supports one-click loading for "Nagiura Sea Breeze Notes (Shared Reading Demo)" so you can immediately try page turning, bookmarks, and page-level annotations. Fresh worlds also offer a light four-step starter flow: waking up, drinking water, writing an essay, and browsing the bookstore.
  • One-Click Model Connectivity Test: The desktop "Settings" page adds a direct model endpoint test button that immediately returns response latency or exact error reasons—saving you from blind troubleshooting.

Related links: GitHub Release v0.6.0 · Windows Desktop Install

v0.5.1 · Body Rhythms, Morning/Evening Streets & Desktop App (GitHub prerelease)

Public prerelease · Segmented test suites and release manifest checks passed · Launches alongside the Windows desktop app

This release bundles recent work around daily routines, neighborhood details, carry-along photos and manuscripts, and the desktop client into a ready-to-install prerelease:

  • Native Windows Desktop Client: Introduces a ~5 MB admin-free installer (installation guide) that lives in the system tray, auto-detects WSL 2 on first launch and guides environment setup, and includes Overview, streaming quote-reply chat, street & interior floorplans, manuscript diffs, and a WeChat QR login panel.
  • Rest & Sustenance Rhythms: Adds time-based rhythms for drowsiness/rest, drinking water, and light meals, with actions advancing over real elapsed time (currently a lightweight rhythm rather than a full hunger/nutrition stat system).
  • Morning/Evening Streets & Readable Landmarks: The same street shifts in appearance between morning and evening, and roadside fixtures and reading corners let you stop and read their contents in detail.
  • Photo Album, Journal & Manuscript Continuation: Rounds out camera snapshots, album browsing, shared reading annotations, and pausing/resuming unfinished manuscripts with historical revision diffs.
  • Engineering Cleanup & Sanitization: Standardizes installer version numbers and explicit memory module configuration, and thoroughly strips internal test addresses from the public source.
v0.5.1 Historical Scope & Boundaries

Completed targeted segmented test suites, 9 offline sanitization checks, MANIFEST.json and ZIP hash verification, and live desktop integration testing. That round did not re-run the legacy 40,000+ host full regression suite or run a 24-hour continuous live-LLM soak test (note: the randomized worlds and moving suitcase still pending at that point later landed in v0.7.0).

v0.4.0 · Multi-Leg Travel & Deferred Tasks (GitHub prerelease)

Public prerelease · 263 world & body tests passing

Building on v0.3's single-trip loop, v0.4 solves multi-leg journeys and interleaving multiple tasks on hand:

  • Continuous Multi-Leg Journeys: Trips to distant spots automatically split into sequential segments (e.g., Bedroom → Living Room → Street → Bookstore), saving progress after each leg so stopping midway never causes erratic jumps.
  • Suspend Multiple Tasks, Focus on One at a Time: Unfinished tasks can be parked with their wait conditions while working on something else, then picked back up once conditions are met—only one task ever runs in the foreground.
  • Multi-Day Weather & Neighborhood Happenings: Weather shifts and small neighborhood events span multiple days, evolve in phases, and wrap up naturally instead of looping endlessly.
  • Clearer Status Receipts: Fixed occasional action-ID mix-ups across activities, and clearly separated "action rejected" from "outcome temporarily unknown" instead of collapsing both into one generic error.
  • Manuscript Version Diffs: Added revision history lists and line-by-line addition/deletion views for managed manuscripts, automatically referencing the previous version's summary when resuming.

v0.3.0 · Travel, Spending & Continuous Loop (GitHub prerelease)

Public prerelease · 8 groups / 51 core mechanism checks passing

Connects heading out, waiting in transit, changing plans midway, shopping in stores, and returning home to resume prior work into a pauseable, resumable continuous loop:

  • Real Map-Graph Pathfinding: Resolves locations and room doorways directly from the active map; ambiguous names or blocked paths are reported honestly instead of relying on hardcoded teleports.
  • Pause Mid-Trip Without Re-walking: Pausing only halts upcoming legs—the leg already underway finishes accurately, and resuming picks up from that exact checkpoint.
  • No Duplicate Execution Under Network Jitter: If an action receipt is lost after submission, the engine reconciles against the ledger first instead of blindly retrying and executing the same action twice.
  • Daily Model Call Budgets: Supports per-day and per-session request caps, guaranteeing zero silent background quota drain while paused.
  • In-Shop Spending & Persistent Traces: Drinks or reading material bought in shops are genuinely consumed and logged in carry records, informing subsequent chats and choices; also supports checking shop opening schedules for upcoming days.

v0.2.0-rc3 · In-Chat Movement & Transit Awareness

Released: October 14, 2026

  • Send Them Out in One Line: Added the world_move tool so you can tell them directly in the terminal, WeChat, or Telegram to head to the convenience store or park—non-adjacent locations route automatically via streets.
  • Realistic Walking Times: Each leg takes 5 to 13 minutes depending on distance; message them along the way and they can tell you roughly how many minutes remain until arrival.
  • Permission Fix & Test Coverage: Fixed memory safety rules falsely blocking the movement tool, and added 16 targeted tests plus file manifest validation.

v0.2.0-rc2 · Install & Upgrade Metadata Fixes

Fixed stale version numbers left in the rc1 archive's upgrade manifest, added an automated packaging verification script to prevent version mismatches, and corrected a command typo in the Telegram binding guide.

v0.2.0-rc1 · Autonomous Routine & Map Editor

Released: October 13, 2026

  • Background Autonomous Rhythm (Off by Default): When enabled, even when no one texts them, they wake on schedule to look around, go for a walk, or continue an unfinished essay.
  • Verified Outcomes Only: Prevents the LLM from claiming "I finished writing it" when nothing was saved—actions are only recorded in the ledger after the underlying service confirms success, and uncertain states are marked honestly.
  • Built-in Offline Map Editor: Ships with a visual spatial editor and multiple town templates so you can draw walls, place doors, and arrange furniture right in your browser.

v0.1.0-rc9 · Agent-Assisted Install & Community

Released: October 10, 2026

  • AI Agent Install Spec: Published AGENT_INSTALL.zh-CN.md so you can copy standard instructions to tools like Claude Code or Codex for automated environment checks, instance isolation, and SHA256-verified installation.
  • Community Channels: Opened the official QQ community group (1126943805) and Telegram channel (@nyairoai) for issue feedback and configuration tips.
  • Docs Site Polish: Refined the homepage hero and documentation reading typography.

v0.1.0-rc6 · One-Command Update & Rollback

Released: October 6, 2026

  • Smooth In-Place Upgrades: Added nyairo update, which replaces only the program directory under ~/.local/share/nyairo while leaving chat logs, memories, keys, and SOUL.md in ~/.nyairo intact.
  • One-Command Rollback & Recovery: Roll back to the previous version anytime with nyairo update --rollback without losing new chats from the interim, or repair an interrupted download with nyairo update --recover.

v0.1.0-rc5 · Custom Persona & Privacy Hardening

Released: October 4, 2026

  • Decoupled Persona Template: New instances default to a clean, neutral SOUL.md template so you can freely configure name, form of address, and personality.
  • Short-Turn Context Fix & Tool Guardrails: Fixed occasional missed context in brief exchanges, and restricted arbitrary file-reading tools by default in memory mode so the model cannot bypass "stop recalling" settings by reading old logs.

v0.1.0-rc4 · First Public Preview

Released: October 2, 2026

Built nyairo's foundational skeleton: local SQLite long-term memory, daily state persisted across restarts, and the initial location and posture awareness interface.
