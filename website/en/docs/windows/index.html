Installing on Windows (Desktop Client + WSL2)

We recommend the admin-free native Windows desktop client (with a two-step SmartScreen vector guide and automated environment setup); pure WSL 2 CLI installation is also supported.

On this page (4)▾
  • Option 1: Windows Desktop Client (Recommended)
  • How to Handle "Windows protected your PC" (SmartScreen Guide)
  • Prerequisites: Enable WSL 2 and Ubuntu
  • Option 2: Pure WSL Terminal CLI Installation

Option 1: Windows Desktop Client (Recommended)

Windows 10 / 11 users can install the native desktop client directly (about 6.0 MB; installs into your current user directory with no administrator privileges required):

  1. Download the installer: nyairo-0.8.0-setup.exe (SHA256: 36ed8ef7d4aabeb86e1a55fff298eaa2df4a995cd603b845bb885cf81ef76eb8);
  2. Double-click to install and launch nyairo (if a SmartScreen prompt appears on first launch, follow the two-step diagram below: click "More info → Run anyway"). The app icon stays accessible in the bottom-right system tray;
  3. On first startup, the client walks you through a two-step setup: Step 1 prepares the environment automatically (downloads and verifies the v0.8.0 release bundle → installs Python dependencies → initializes an isolated personal data directory → generates a local communication token → starts the gateway → runs a health check); Step 2 handles configuration (set how to address your companion, their pronouns, model name, and API Key on the spot, or connect to a local Ollama instance—see the Zero-Barrier Beginner Model Guide);
  4. Click "Finish and Start" to open the main window. For details on each view and keyboard shortcuts, see the Desktop Client User Guide.
Uninstalling Will Not Delete Memories

The desktop UI is installed under %LOCALAPPDATA%\Programs\nyairo, while chat memories and persona files live separately inside your WSL personal data directory. Uninstalling the desktop client only stops the gateway and cleans up auto-start entries and window caches—your personal data stays untouched (see Data Directories, Backups, and Uninstallation).

How to Handle "Windows protected your PC" (SmartScreen Guide)

Why does this prompt appear? Microsoft shows this standard warning for newly released independent open-source software that has not purchased a commercial EV code-signing certificate (which costs thousands of RMB per year)—it does not mean the file is unsafe. Follow these three steps to verify and run it:

  1. Step 1 · Click "More info": Below the "Windows protected your PC" warning text, click the underlined "More info" link;
  2. Verify the SHA256 checksum (optional): Open PowerShell in the folder containing the installer, run Get-FileHash .\nyairo-0.8.0-setup.exe -Algorithm SHA256, and confirm the output matches 36ed8ef7d4aabeb86e1a55fff298eaa2df4a995cd603b845bb885cf81ef76eb8 published on the official site character for character;
  3. Step 2 · Click "Run anyway": Click the newly revealed "Run anyway" button at the bottom of the window to start installation normally.

Prerequisites: Enable WSL 2 and Ubuntu

If WSL 2 has not been enabled on your computer yet (the desktop client will also remind you on first launch), it only takes a few minutes to set up:

  1. Search for PowerShell in the Windows Start menu, right-click it, and choose Run as administrator;
  2. Paste the command below and press Enter:
powershell
wsl --install -d Ubuntu

If prompted to restart your computer after installation finishes, reboot first. Next, open Ubuntu from the Start menu and follow the prompts to set an ASCII username and password (nothing appearing on screen while typing your password in a Linux terminal is normal—just type it and press Enter). Once that is done, open the nyairo desktop client and it will handle the rest of the setup automatically.

Option 2: Pure WSL Terminal CLI Installation

If you prefer working without a GUI and want to run everything from the terminal, open your Ubuntu terminal and paste this single line:

bash
curl -fsSL https://nyairo.com/install.sh | bash

If you prefer to verify the checksum before running the installer, use these commands to check the SHA256 hash first:

bash
curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.8.0/nyairo-v0.8.0.zip
curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.8.0/nyairo-v0.8.0.zip.sha256
sha256sum -c nyairo-v0.8.0.zip.sha256
python3 -m zipfile -e nyairo-v0.8.0.zip "$HOME/apps/nyairo-v0.8.0"
cd "$HOME/apps/nyairo-v0.8.0" && bash scripts/bootstrap.sh

Follow the on-screen prompts to enter your model API Key. Afterward, whenever you open Ubuntu, simply type nyairo to start chatting.
