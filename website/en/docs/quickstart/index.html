Getting Started: Your First Run

Choose the installation method that suits your machine: Windows users can install the desktop app directly, and beginners can start chatting with a 5 CNY (~$1) DeepSeek API key or free local Ollama.

Choose Your Install Method

All you need before starting is an internet-connected computer and an LLM endpoint (either a 5 CNY / ~$1 DeepSeek API key or free local Ollama). Pick the path for your OS:

  • On Windows 10 / 11 (Recommended): Download the ~5.8 MB Windows Desktop Installer. Double-clicking it automatically detects WSL 2 and walks you through setting up the backend—no terminal commands to memorize. See Installing on Windows for complete steps and Desktop Client Guide for UI usage.
  • On Linux, or if you prefer pure terminal: Follow the one-line installation steps right below.
  • If you use Claude Code, Codex, or another coding assistant: Copy the standard instructions from Let an AI Agent Install It and let it handle the installation for you.

Windows SmartScreen Two-Step Guide

As an independent open-source project, nyairo does not yet purchase an expensive annual commercial EV code-signing certificate, so Windows SmartScreen may show a routine warning when you launch nyairo-0.7.0-setup.exe for the first time. Click through in two quick steps (no administrator privileges required):

  1. Click "More info" below the prompt text to expand the installer details;
  2. Optionally verify that the installer's SHA256 matches the official hash 174e459727af67c5d97204abd69dd7ce0741ed056a084fc64ba78a187bc14dd8, then click "Run anyway" at the bottom right to enter the setup wizard.

Linux / WSL One-Line Install

Open your Linux terminal (Windows terminal-only users: open the Ubuntu window first), paste the command below, and press Enter:

bash
curl -fsSL https://nyairo.com/install.sh | bash

Prefer to verify the archive before running? Download the official package and checksum file step by step:

bash
curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.7.0/nyairo-v0.7.0.zip
curl -fsSL -O https://github.com/L1AN929/nyairo/releases/download/v0.7.0/nyairo-v0.7.0.zip.sha256
sha256sum -c nyairo-v0.7.0.zip.sha256
python3 -m zipfile -e nyairo-v0.7.0.zip "$HOME/apps/nyairo-v0.7.0"
cd "$HOME/apps/nyairo-v0.7.0" && bash scripts/bootstrap.sh

No need to pre-install Python or Git. The script automatically downloads and verifies the official v0.7.0 release bundle, configures a Python 3.13 runtime, and creates your personal data directory under ~/.nyairo.

Once the terminal prints [5/5] 程序安装完成 (installation complete), it automatically enters the model setup wizard:

  1. Use the Up/Down arrow keys to select your model provider;
  2. Paste your API Key (if you are using a third-party compatible endpoint, fill in the Base URL as well);
  3. Press Enter to save and enter the chat interface directly—send "Hello", and once you get a reply, you're all set.
Getting "curl: command not found"?

A few minimal Ubuntu images do not ship with curl pre-installed. Run sudo apt update && sudo apt install -y curl first, then re-run the installation command above.

Beginner Model Setup: 5 CNY (~$1) DeepSeek Key or Free Ollama

Never applied for an API key before? Don't worry—nyairo's deterministic foundation doesn't require expensive models. Pick either zero-barrier option below to get running:

  • Option A (Easiest · No GPU Required): Get a DeepSeek Key for 5–10 CNY (~$1–$1.50): Open platform.deepseek.com in your browser, sign up and log in, and add 5–10 CNY on the Top Up page (everyday chat costs only a tiny fraction of a cent per turn, so it lasts a long time). Click "API keys → Create API key" on the left, copy the generated sk-... key, paste it into the desktop client under "Settings → Model" (select deepseek-chat), and click "Save" followed by "Test Connection".
  • Option B (Completely Free · Zero Cloud Traffic): Connect Local Ollama: Visit ollama.com to install Ollama and pull a lightweight model (e.g., ollama pull qwen2.5:7b), keeping it listening on http://127.0.0.1:11434. In the desktop app under "Settings → Model", select the local Ollama / OpenAI-compatible interface (set the URL to http://127.0.0.1:11434/v1 and key to ollama). All conversation data stays strictly on your machine (see Daily Launch, Persona & Models for step-by-step instructions).

How to Chat After Installation

  • Desktop app users: Click the nyairo icon on your desktop or in the bottom-right system tray to open the window, and use the sidebar to switch between "Overview", "Chat", "Neighborhood", "Memory", and "Settings".
  • Terminal users: Open your terminal and run nyairo to keep chatting; run /chiyo_status to check whether memory (READY) and daily state (IDLE) are online; run nyairo setup model anytime to switch models.
  • Connect to WeChat on your phone: Want to keep chatting from your phone while you're out? Follow Connect WeChat to scan a QR code and pair it.

Set Their Name & Personality

The default persona is a clean blank slate. To name them, set their speaking tone, and choose how they address you, open SOUL.md inside your personal directory with an editor:

bash
nano "$HOME/.nyairo/SOUL.md"

Write in plain everyday language what their name is, whether their personality leans quiet or lively, and what they should call you. Press Ctrl + O then Enter to save, and Ctrl + X to exit—your new persona takes effect on the next conversation.
